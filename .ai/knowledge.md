# 长期知识库（跨工具共享，只追加，请勿删历史条目）

> **为什么需要这个文件？**
> zcode 的 Project Memory 写在它自己的本地存储里，官方明确说不能查看/清除、不进 Git；
> qoder 的 Auto-Memory 写在 `~/.qoder/projects/<路径slug>/memory/` 下，只对 qoder 可见。
> **两边互不相通。** 想让另一个工具也知道某件事，只能手写在这里。
>
> 追加方式：`python3 .ai/bridge.py knowledge "内容"`
>
> **适合写：** 环境坑、标定/外参结论、版本约束、真机调试经验、用户偏好、某个方案为何被否决。
> **不适合写：** 临时报错堆栈、单会话中间状态（那些写进任务卡的工作笔记）。
