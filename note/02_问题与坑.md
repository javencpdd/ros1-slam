## 坑4 · sudo 时间戳跨 Bash 会话失效 + 管道子 shell 内裸 sudo 失效（登记日 2026-10-04 · 源于 P1）
- 症状：sudo 凭据跨 Bash 会话不延续；管道子 shell 内裸 sudo 报「a terminal is required」（P1 块 3 首跑失败）。
- 根因：sudo 时间戳按会话记账，跨块未刷新凭据；无终端的管道子 shell 内 sudo 无法弹密。
- 处置：固化两条施工规约——①每块开头 `PW='***'; printf '%s\n' "$PW" | sudo -S -p '' -v` 刷新凭据，块内裸 sudo；②证据落盘改「重定向到文件再 cat」，不在管道子 shell 内裸 sudo。P1 块 3 补验证行后原命令原样重跑成功（01_部署记录.md P1 偏差 2）。
- 计划书是否需要更新：建议写入施工 SOP 注记（P0.4 sudo 规约处补一句「跨块必须重新 -v 刷新；证据采集用重定向落盘」）。

## 坑5 · qnx2ros UDP 43897 被占用 → bind error 类问题（登记日 2026-10-04 · 源于 P3b/Q12 闭环）
- 症状：P3b 首次采图 qnx2ros 启动即 bind error 死亡，/imu/data 无输出，faster_lio 拿不到 IMU 无法建图（Q12 修复前）。本机根因实测：root 侧 foxy 栈 **jetson2motion**（订阅 /cmd_vel 直发底盘的生产进程）已占用 UDP 43897，与 qnx2ros 监听端口硬冲突——主理人主机侧复现在案。
- 根因：ROS1 沙箱与 foxy 生产栈同主机抢同一 UDP 端口；P0.5 双查正则只覆盖「jetson2motion 进程存在性」（坑1 常态共存判定），未把「端口级占用 ⇒ bind 类节点必死」的因果链写明，作业单 2.2 异常判据虽列 bind error 但只给停机指引、无前置检查手段。
- 处置：Q12 按 v4.1 §5.1 走变更流程切 B——faster_lio 改 /livox/imu（Mid-360 内置，实测 **199.9 Hz**）+ Mid-360 工厂外参（单位阵/[-0.011,-0.02329,0.04412]，extrinsic_est_en=true 在线精调），04 台账两条登记（commit a821e01），**Q12 正式关闭**，修复后首张有效图落盘（b467c69）。规约增补：**凡 bind 类节点（qnx2ros 及后续监听型桥）起前先 `ss -ulnp | grep <port>` 查端口级占用，不只查进程名**（端口被占 = 该节点必死，先裁决端口归属再起）。
- 计划书是否需要更新：建议 v4.x ① P6（mode_localize）前置核对增补端口级检查行——mode_localize 若仍依赖 /imu/data（hdl_localization 链），须先裁决 UDP 43897 归属（与 Q8 关联：动 root 侧 jetson2motion 需用户确认）或整链沿用 /livox/imu 分支；② 作业单模板 0.2 节补一行「bind 类节点起前 ss -ulnp 查端口」。登记人：验收工程师-小美（代登记，2026-10-04）。
