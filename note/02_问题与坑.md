## 坑4 · sudo 时间戳跨 Bash 会话失效 + 管道子 shell 内裸 sudo 失效（登记日 2026-10-04 · 源于 P1）
- 症状：sudo 凭据跨 Bash 会话不延续；管道子 shell 内裸 sudo 报「a terminal is required」（P1 块 3 首跑失败）。
- 根因：sudo 时间戳按会话记账，跨块未刷新凭据；无终端的管道子 shell 内 sudo 无法弹密。
- 处置：固化两条施工规约——①每块开头 `PW='***'; printf '%s\n' "$PW" | sudo -S -p '' -v` 刷新凭据，块内裸 sudo；②证据落盘改「重定向到文件再 cat」，不在管道子 shell 内裸 sudo。P1 块 3 补验证行后原命令原样重跑成功（01_部署记录.md P1 偏差 2）。
- 计划书是否需要更新：建议写入施工 SOP 注记（P0.4 sudo 规约处补一句「跨块必须重新 -v 刷新；证据采集用重定向落盘」）。
