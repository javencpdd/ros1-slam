>
> **Codex 专属三条（2026-10-24 接入）**
> 1. **读得到**：Codex 原生读 `AGENTS.md`，从 git 根向下拼接到当前目录，所以在项目任意子目录启动都带得上根指针。

## 2. 红线（本项目已有规矩，逐条都要守）

1. **不要整读巨型文档。** `note/进度/00_总览.md` 自 R546/批202（路甲二期）起为「档头＋索引」形（约 460 行；每批一条索引行，全文在各阶段目录 `批次记录/Rxxx.md`），但 `note/04_配置改动diff.md` 仍 1.3MB 级、`note/进度/总览分册/00_档头历史_档案.md` 约 620KB、`note/进度/SCAN集成/` 229M。
   一律先定位再抽取，例如：
   ```bash
   awk '/^## 结构变更/,0' note/进度/00_总览.md                  # 条目区索引行（每批一条＋全文指针）
   awk '/^### G0/,/^### G1/' note/进度/总览分册/01_Gate状态.md  # Gate 状态（人读区已外迁）
   ```
   整篇 `cat` 会把上下文撑爆，也会让你抓不住重点。
2. **进度真身只有一个**：`note/进度/00_总览.md`（时间线口径；批次全文在阶段目录 `批次记录/`，以索引行指针为准）。**别信任何摘要里的旧状态**。
3. **A6 单向流**：本工作区由开发侧对照库单向复制建立，**绝不反向写入**；
   `/home/ysc` 视为只读，要用先复制到本目录再改。
4. **第三方包原样复制、一字不改。** 唯一许可的例外是 faster-lio 存盘路径的隔离改写，
   且必须登记进 `note/04_配置改动diff.md` 并受隔离自检第 `[8]` 项监控。
5. **三态通道口径 PASS / FAIL / INVALID**：INVALID 不入串，也不得吸收并存的 FAIL。
   见 `note/06_三态通道普查.md`。
6. **P8 计划书同步纪律**：动了话状体 / 判据载体，要按 `note/05_复验作业单.md` F 段回写。
7. **不要在仓库根目录建「任务名」文件。** 过往已产生过 `Gate`、`timeout`、`v3`、`ros1-slam`、
   `lite3_drivers，FAILED`、`**产出**：部署架构师` 等一堆 0 字节垃圾文件——
   **进度写进 `note/` 或任务卡，不要建空文件占位。**
8. **落盘属主与 ACL（对应 `note/02_问题与坑.md` 坑17）**：
   以 `ysc` 落盘会让属主漂移成 `ysc:ysc`，导致 `ros1-slam` 账号落到 `other::r--` 写不动。
   → **每次编辑后立即** `setfacl -m u:ros1-slam:rwx <文件>`（目录加 `-R` 与 `-R -d`）。
   `bridge.py` 已内置此逻辑，**但你用 Edit / tee 等其他方式写文件时必须手动补。**
9. **验证身份**：优先走 `scripts/as_ros1slam.sh`；没有 sudo 交互通道时按坑17 的无 sudo 路径处置。

## 3. 任务纪律（防串台）

1. **同一时刻只有一条战线**：全局只有 `current_task` 一个，`resume` 只吐它。
   被要求做别的事，先 `handoff` / `done` 再 `new`。
2. **作用域白名单**：任务卡写明 scope（如 `ws/src/40_navigation/`），**不在列表里的文件不要改**，
   哪怕看起来该顺手重构。
3. **状态迁移必须走脚本**：`TASKS.md` / `HANDOFF.md` / `state.json` 由 `bridge.py` 生成，**禁止手改**。
   唯一可手写追加的是任务卡里的「工作笔记」。
4. **epoch 核对**：`HANDOFF.md` 顶部 `epoch: N` 小于 `bridge.py json` 输出的当前值 = 读到旧快照，重跑 `resume`。
5. **拿不准就问人**，尤其涉及上机运行的 actual flag、雷达外参、TF 树。这项目有明确的
   主理人 / 小美（判据面）/ 小张（设计面）分工，**该裁定的进 `note/进度/00_裁定请求单_2026-10-09.md`**，别自己拍。

## 5. 收工四步（强制）

```bash
python3 .ai/bridge.py note    T-20261016-01 "本轮成果 + 验证结论"
python3 .ai/bridge.py handoff T-20261016-01 --to zcode \
  --summary "下一步做什么 / 坑在哪 / 别碰什么"
python3 .ai/bridge.py check
```

摘要必须包含三件事：**下一步具体动作**、**已试过无效的方案**、**作用域外的雷区**。
**禁止**写「交给下一个 agent 继续」这种等于没说的话。

## 8. 为什么不做别的方案

| 方案 | 结论 |
|---|---|
| 互导两边私有记忆 | ✘ 格式闭源 + 厂商可能变更 + 有写坏库风险 |
| memU（14.5k star, Apache-2.0） | △ 定位合适但官方 host 矩阵不覆盖 zcode / qoder，需自写 adapter + 自备 embedding |
| MCP 记忆服务 | △ 引入 DB 依赖，对一个 ROS 沙箱过重 |
| **共享黑板 + bridge.py** ✔ | 零依赖、纯文本、可 git diff、人和 LLM 都能读、换任何工具都不失效 |

> AGENTS.md 类指令的遵守率是**概率性**的（超 200 行明显下降、冲突指令随机取舍）。
> 所以**状态迁移务必走 bridge.py**，让脚本而不是大模型来保证一致性。
