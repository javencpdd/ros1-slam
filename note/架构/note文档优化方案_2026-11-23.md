## 3. 四层架构（本方案骨架）

```
① 原始层（不动，权威）   R 正文、evidence、计划书原文、04/02/05 台账、01_批次
② 编译层（可重建）       日期 / 模块 / 里程碑 / 代际 / 台账主题速查
③ 索引层（可重建）       证据索引、归档索引、台账索引、横向台账导读、架构地图
④ 入口层（人读，稳定）   README → 架构真源 → 进度入口 → v8 能力表 → 编译层索引
```

**三条权威规则**（每份生成物页头都要写）：

1. 编译/索引层只做搬运与定位，**不是权威**；
2. 每行必须链回原始层文件，读者能一步下钻；
3. 冲突时以原始层（R 正文、台账）为准，索引层不许改写结论。

## 9. 命名与位置约定

- 索引类：`<源件名>_索引.md`，与源件同目录（04／05／02 已统一）；
- 导读类：放 `note/` 根，名称带用途（如 `横向台账导读.md`）；
- 编译类：`note/编译/`，页头三行固定（自动生成／非权威／每行链回正文）；
- 时间标签：`时点快照`、`已归档`、`仅供追溯`，与 `归档/README.md` 的标签表一致。
