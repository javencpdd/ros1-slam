# 高度契约 T1/T2/T3（2026-11-27，按源码与 URDF 实测）

## 先纠正上一轮的一处语义错误
之前把 `map→camera_init` 的 z 设成 **0.11**，理由写的是"机体高"。
实测源码后发现这是**错的量**：LIO 的 `body` 不是 base_link。

证据链：
1. `faster_lio/src/laser_mapping.cc:686` → `child_frame_id = "body"`；
2. Gazebo IMU 传感器挂在 `rslidar` 链上，且 `<frameName>rslidar</frameName>`
   （`lite3_planar.urdf.xacro:123-135`）⇒ 进 LIO 的 IMU 数据**就是 rslidar 系**；
3. 于是 LIO 的 `body` ≡ **rslidar 系**，LIO 输出的位姿是**雷达/IMU 的位姿**，不是 base_link。

⇒ `camera_init` 的原点高度应是**雷达离地高 0.45 m**（`lidar_z 0.34 + 实测基座 0.11`），
   不是 0.11。0.11 是 base_link 离地高，两者差 0.34。

## 三段变换（全部来自几何，无一项拟合）
| 段 | 含义 | 值 | 来源 |
|---|---|---|---|
| T1 | 世界锚点 `map→camera_init` | xyz `(5.2, 2.45, **0.45**)`，yaw 0 | m2_mapping 的 spawn + 雷达离地高 |
| T2 | 传感器→机体 `body→base_link` | xyz `(0, 0, **−0.34**)`，rpy `(0, **−15°**, 0)` | URDF `base_to_rslidar` 的**逆** |
| T3 | 机体→接触点 | `contact_z = base_z − 0.11` | URDF 基座离地 0.11 |

T2 的推导：URDF `base_to_rslidar` = xyz(0,0,0.34) rpy(0,15°,0)，其逆为
`Rᵀ` 与 `−Rᵀp`，因 p 本身由同一 R 作用于 (0,0,0.34) 得到 ⇒ `−Rᵀp = (0,0,−0.34)`，
`Rᵀ = R_y(−15°)`。**不是恒等变换**。

## 用这套几何重算实测（LIO 偏置 lio_z = −0.078）
```
body_z  = 0.45 + (−0.078)        = 0.372
base_z  = 0.372 − 0.34·cos15°    = 0.372 − 0.3285 = 0.0435
contact = 0.0435 − 0.11          = **−0.067**
```
即：当前 LIO 认为接触点在地面**下 6.7 cm**。这是**估计误差**，
与"表观 converted_z = +0.032"不是一回事——后者是拿错锚点量出来的巧合。

## 对关联容差的含义
- 容差要覆盖的是 `|contact − 0| ≈ 0.067`（跨初始化 0.03~0.07 波动），**不是 0.032**。
- 因此之前"0.05 量级够用"的结论**作废**：0.05 盖不住 0.067。
- 正确顺序：先按 T1/T2/T3 接线（纯几何），再重测 contact 残差，最后才谈容差。
- 配置里 `support_assoc_tol_m` 保持 1e-6 不动。

## 2026-11-28 更正（旧文保留，以本段为准）

- 原文 T2 的“−Rᵀp = (0,0,−0.34)”推导**错误**：URDF `p=(0,0,0.34)` 是父系平移，不是 `R·(0,0,0.34)`。正确逆平移为 `(0.34·sin15°, 0, −0.34·cos15°) ≈ (0.0880, 0, −0.3284)`，旋转为 `R_y(−15°)`。
- 原文“camera_init 由首帧 IMU 姿态初始化、世界系已重力对齐”**无源码依据**。`imu_processing.hpp` 的 `IMUInit` 只估 `grav`，不设置 `rot`；活体静止 IMU 加速度 `(-2.532, 0.011, 9.476)` 也证明 body 带 15° 倾角。`camera_init` 就是首帧 body 系。
- 因此 T1 也必须带 `R_y(+15°)`；只改 z 或只给纯平移 T2 都不成立。统一实现见 `ws/src/90_platform/v8_platform/framework/pose_contract.py`，证据见 `note/进度/00_专题/v8_map_loc_2026-11-24/evidence/a2_tf_contract_20261128/`。
- 原文“contact 残差约 −0.067”仍作为旧读数保留；新接线后的活体 z 残差约 −0.056 m（`loc_minus_gt_m=0.0608` 的三维值），容差未改。
