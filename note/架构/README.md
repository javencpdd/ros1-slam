## 四、怎么用

1. **要动代码**：先 `项目架构与目录` + `工程标准`，再看对应那一轮的设计件。
2. **要查「这个接口什么意思」**：`运行链路与接口` → 它的表来自 manifest；接口以 manifest 为准。
3. **要判断某份设计还作不作数**：看它属于上面哪一类 —— 第二类绑日期，第三类是一次性分析，都不构成「当前结构」。
4. **新增文件放哪**：真源才进第一类；某一轮的设计/验收按 `主题_YYYY-MM-DD.md` 命名；一次性分析建议同时登记进本页第三类。
