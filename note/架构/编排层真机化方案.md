## 2. 目标分层（重构后的职责边界）

```text
编排层（本树）     决定 WHEN：请求路径 → 等路径 → 下发目标 → 等到点 → 停顿 → 恢复
                   不算路径、不写速度（除零停）、不决定重规划节奏
规划层             planner/topic_node.py：读 goal → 算 /global_path → 发 status
控制层             局部规划器 + TEB/MBF：轨迹与速度
安全层             60_safety mux / 超声保底 / ros2qnx 底盘守护：唯一速度写者
```

真机可用性要求：编排层的**话题、判据、超时**必须来自配置而非代码；依赖必须能进镜像；启动必须可选、默认不改变现有真机行为。
