## 二、B0 期间发现并已修的环境缺口：容器看不到 `archive/`

现读事实：

| 项 | 读数 |
|---|---|
| 容器内 `/opt/ros1-slam/` 目录（修前） | 有 `data docker logs note opt scripts sim_repo sim_ws subprojects tooling ws`，**无 `archive`** |
| `docker/docker-compose.yml` 挂载表（修前） | `&ros-volumes` 锚点与 sim-viz 自写列表**都未挂 `archive`** |
| 容器内预检（修前） | `[①ISO] ISO_RC=1`，ISO 件报 `[v8-isolation] rejected: moved costmap plugin package missing from both ws/src and archive` |
| 临时容器补挂 `archive` 只读后 | `PREFLIGHT VERDICT rc=0`（放行），整条窗口 `rc=0` |
| 正式补挂 `&ros-volumes` 并在规范容器重建后 | `[①ISO] ISO_RC=0`，窗口 `BT_NATIVE_RUNTIME_RC=0` |

根因：B 链窗口被拒窗的是**挂载面缺口**，不是代码缺陷、也不是本卡改造引入。

来源：2026-11-22 退役批次 `b38ec273` 把 `lite3_costmap_layers` 整包 `git mv` 进仓根 `archive/`，而容器只挂到 `ws/src` 等子目录；该批 04 段末已自留「ISO 与 DC 的定性仍须机器侧看到具体行」——本次在机器侧看到了，红因即此。

影响面：凡在容器内跑 ISO 闸的路径都会红（窗口预检、B5 门禁串），**不止本卡**。

处置（已做）：`docker/docker-compose.yml` 的 `&ros-volumes` 锚点补一行 `- ../archive:/opt/ros1-slam/archive:ro`（`sim`／`slam`／`slam-host` 均生效），`docker compose up -d --no-deps --force-recreate slam` 与 `... sim` 重建两个容器。只读是安全的：`archive/` 不参与 catkin 构建，`pyst_face.txt` 注记也明写归档副本不再受 PYST，没有门禁会往里写 `__pycache__`。

遗留：`sim-viz` 走自己的挂载列表、未补 `archive`。该容器只做 GUI 显示、不跑门禁与窗口，暂不动；若将来要在它里面跑预检，先补挂。
