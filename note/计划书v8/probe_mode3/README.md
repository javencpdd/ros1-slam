## 3. 结论与主备路线取舍

1. **SCAN mode3 的接缝数学只在「单调高度段、段长≫0.5 m、输入 z 为地面系、body_height 显式配置」这四个前提下可用。** 段外（非单调剖面、多高度列、同高起终）单次搜索结构性无解（C2/C3/C4），与地图质量无关。
2. **主路线**：support_map 全局规划（V8-08/09）按转层边把路线切成**单调段**，逐段交给 mode3/A*；适配器契约（对应 22 号 §TF 边）＝输入 z 地面系、单次补偿、`body_height` 显式定值、转层进出点作为 waypoint 显式锚定进 /initial_path。
3. **备路线**：若第二切片实测发现段内接缝仍丢高度（B2 的 0.5 m constexpr 与短坡道不可调和、且不可配），则该段弃用 mode3 接缝、以支撑图原生局部规划替代——23 号 V8-10 交付物已留「SCAN 适配**或备选**」口，不预设必用 SCAN。
4. 本批不裁定源码是否要改（如 min_dist 参数化），那是第二切片的运行域证据与授权面的事。

## 4. 边界

- 复现到 waypoint 列表与搜索平面 z 为止；`planGlobalTrajWaypoints` 多项式平滑、occupancy 内部、真实运行行为归第二切片（独立环境甲、固定输入 hash、无头运行）。

## 5. 运行时附录（R633—R635 实证，详见 note/进度/v8/M0/26-10-25/）

离线判定在独立环境甲的真实运行中逐条对上，另得三个离线未建的新事实：

1. **A* 修复搜索的池＝碰撞段中点 ±2.5 m 方盒**（`planner_manager.cpp:68` 传池 (100,100,100)×步长 0.05；`dyn_a_star.h` `Coord2Index` 以搜索中点为参照）——修复搜索的横向可达范围远小于 10 m 滑窗地图，盒外逃逸路线按构造不可达。wall 案例（墙跨 y±4 ≥ 池宽 ±2.5）因此几何无懈可击：A* 失败 1609 次、FSM 永卡 GEN_NEW_TRAJ。
2. **优化器梯度回退会掩盖 A* 失败**（slab 案例）：双层列 A* 21/21 全败（无超时、无池溢出，开集耗尽；理论窄逃逸带仅 0.27 m 未被找到），但 bspline 优化器连续松弛绕 +y 板边（末段局部轨迹 y 至 2.06，板缘 2.0）产出无碰撞轨迹进入 EXEC_TRAJ——兜底路线非搜索解、几何未经验证，独立轨迹检查器（V8-10）必需。
3. **单调段内平面搜索可用**（step 案例，C1 运行时正控）：台阶跨越（一步 0.4 m、waypoint 保留）A* 零失败且成功出径——支撑「支撑图切单调段、段内交 mode3」的主路线前提。
