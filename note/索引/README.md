## 与编译层的分工

- 本目录：**台账类**（谁改了什么、问题清单、计划书代际）——面向「查历史动作」。
- `note/编译/`：**批次类**（500 份 R 正文按日期／模块／里程碑／工作包）——面向「查做过什么」。
- 两者都只做搬运，且都在页头写明「非权威」。

## 两条维护命令

```bash
python3 scripts/dev/dev.py docs --check   # 索引层是否与源一致（不一致返回 5）
python3 scripts/dev/dev.py lint            # 断链/孤儿/同名/戳失真/空件（有问题返回 5）
```

两条都是只读；`docs` 重建、`lint` 巡检，互不依赖。收工前各跑一次即可。
