## S7 · 三项遗留问题的归因与处置（2026-11-23 04:3x，真人追问后）

### 一、七个单测错误：一个根因，已修（零改测试代码）

| 项 | 事实 |
| --- | --- |
| 现象 | `local_planner` 126 项里 2 项、`representation` 58 项里 5 项是 loader 级 ImportError |
| 根因 | 两目录各有若干测试用 `import test_xxx as fixture`（同目录平铺写法）；从包根 `python3 -m unittest discover` 跑时模块被装成 `tests.xxx`，平铺名不在 `sys.path` ⇒ 全部 `ModuleNotFoundError` |
| 反证 | 把 cwd 切到 `tests/` 再跑，`local_planner` 37 项 OK、`representation` 77 项 OK —— 测试本身是健康的，坏的是调用姿势 |
| 对照 | `planner/tests/test_ros_node.py` 正好有 `sys.path.insert(0, dirname(__file__))`，所以它从来不报错（同一仓里两种写法并存） |
| 处置 | 在两处 **`tests/__init__.py`**（原为 0 字节）各加 16 行路径垫片：把本目录 **append** 进 `sys.path`；测试文件一字未改 |
| 结果 | `representation` 58 → **77 项 OK**（找回 19 项）；`local_planner` 126 → **161 项 OK**（找回 35 项）；`planner` 68 OK 不变；`v8_platform` 344 OK 不变；两种跑法（包根 discover / 目录内直跑）都成立 |
| 门禁 | SYN／PYST／DC／账构 复跑仍全 rc=0 |
