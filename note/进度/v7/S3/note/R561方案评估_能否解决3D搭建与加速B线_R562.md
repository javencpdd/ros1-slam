## 一、一句话结论

**技术骨架可采，开工前提一条没减。**

R561 给的规划栈路线（`grid_map` 承高程 ＋ 自写 `costmap_2d` 层）是 Noetic 上的正解，可直接当 B 线施工蓝图；但它**没有解决"什么时候能开工"**——四道闸一个都没少，而它建议"剥出来先做"的修 W2 恰好踩在 v7 §1.1 第 69 行的**前半句**（"只做设计面"）上，只援引后半句（"不动竖向几何参数"）不构成免闸理由。

三条主结论里，**一条可采、一条须降级、一条方向反了**（§三）。同时本批用源码解掉了它自己列为"待定性"的那一项，并**另发现第三处传承待核**（§二），这一处比它全文任何一条都更影响后续读数。

## 四、G2／J2 与「浮沙」论断：R561 算术指摘成立，但结论方向反了

### 4.1 它指摘得对的地方

R561 §4.1 摆出的算术是对的：`tan 7.21° ≈ 0.1265`，`h = 0.55—0.59` ⇒ `R_min = 4.35—4.66 m`，而实测 **3.99 m 不在这个区间内**。ax §11.2 与 `必补3` 那两句把「4.2—4.7 m（实测 3.99 m）」并列写在一处，★读起来确实像在说"吻合"，这是可指摘的***。且 `0.55—0.59` 与 `0.4347` 差 0.11—0.16 m，★确属两套标定基准***，不是误差量级。

### 4.2 它推论过头的地方

R561 由此推出"`h` 未定标 ⇒ `R_min` 有 20%+ 摆幅 ⇒ 这两条不闭，**任何近场判据都在浮沙上**"。★这一步不成立***，理由是一句算术：

> 四个候选 `h` 给出的 `R_min` 是 **3.44／3.99／4.35／4.66 m**，**最小值也有 3.44 m**；而近场判据要判的是 `r < 0.5 m`（或 `< 1.0 m`）**有没有地面回波**。★3.44 m 与 4.66 m 之差，对"0.5 m 处有没有点"这个判断毫无影响——两个基准下答案都是"没有"。***

⇒ 「近场地面回波补不上」这个**定性结论**的真正支撑是「发射仰角下界 −7.21° **存在**」这一条几何必然（E2 已确认该下界来自 CSV 图案本身、Zenith 上界 97.21° ⇔ 仰角 −7.21°），★`h` 只影响"贴地首命中在 3.4—4.7 m 之间的哪个位置"，不影响"近场必然打不到"。*** 所以 `h` 未定标是**该定标的记账项**（J2 的 z 窗口径也确实要它），★但它不是近场结论的支撑，把它写成"不闭则一切浮沙"是放大了风险。***

### 4.3 一处对称的指摘（R561 自己也没做到）

R561 §4.1 的算式 `R_min = h / tan(7.21°)` **省掉了安装俯仰 θ**。7.21° 是图案相对雷达本体的下界（E2 已证），若雷达在机体上有俯仰 θ，贴地仰角下界应是 `7.21° ∓ θ`。它 §2.3 自己要求记录 `(h, θ, 站立态)` 三元组，★但 §4.1 的算式只用 `h`——与它批评 R560 的那处是同一类简化***。⇒ 该式子只能作量级估计，须连带 `(h, θ, 站立态)` 三元组才可引用（R310 硬句）。

### 4.4 J2 要拆成两条看

| 子项 | 判定 | 说明 |
|---|---|---|
| z 窗的**坐标系口径**（相对雷达系还是 `base_footprint` 站立态地面） | ★真问题，须裁*** | 与 `h` 定标无关，是"读数以谁为原点"的定义题；R561 建议统一到 `base_footprint` 方向合理，但属口径变更（须裁，非施工侧自决） |
| z 窗的**数值** | 照守 R310 硬句 | 任何 z 窗引用须连带安装位与站立态，★这条不许被 R561 的"定标一次即解决"简化掉*** |

## 五、口径替换（§5.1 四观测量）：三条可采、一条须改定义

| 观测量 | 判定 | 理由 |
|---|---|---|
| 每帧**束数** | ★须改定义*** | 按 E2，本仓每帧 **cast** 射线数恒为 20,000（`<samples>` 是配置常数）⇒ 这个量**没有判别力**，跑出来必然 20,000，与 `ring` 恒 32 属同一类"常数换常数"。R561 写"点云总点数 ÷ 帧数 ← 对比 20000"★基准也错***：点云点数是**命中**数，恒 ≤ 20,000，拿它对比发射数会把命中率当成线数缺口。★有判别力的是"每帧有效命中点数"与"每帧丢索引点数"，两个都要带帧数口径。*** |
| zenith 占用箱数（带分箱粒度） | ★可采*** | CSV 唯一 zenith 原始值在册 **187,919 枚**（ax §11.4，既非 50 也非 32）⇒ 本就无离散环结构，占用箱数是唯一诚实的角分布度量 |
| 方位非空箱数（360 分箱） | ★可采*** | 抓扇区缺失／图案裁剪，与 zenith 箱互补 |
| 等效线密度 | ★须裁*** | 它把 50／32／40 拉到同一把尺，但**"40 线"是厂商对真机的公开口径**，对仿真插件无约束力（★引入外部基准须走外部资料引用规矩，且不得写成仿真达成判据***）。作对表参考可，作判据不可。 |
