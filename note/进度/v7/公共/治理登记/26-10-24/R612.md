## 三、为什么危险

1. ★「这一族已经修过」会让人以为封了口***＝坑91 本体的修只在 VAR 那一件里，动作层面没有闸。
2. ★假红出现在「改指之后」的回归里***＝第一反应是「落点取错了」，往错的方向查（该批头两枚自曝正是这么来的），真正的病在下一行。
3. ★证人文件那一层让「内容没变」与「判读变了」彻底分离***＝复查时可以反复核对文件本身而永远查不到病。
4. ★跨面未验＝对方侧疏漏***＝L1 独立实例只在容器面验过「缺件」那一支、没验宿主面的语种这支 ⇒ 本仓**第四处对方侧疏漏**（前三处＝反证一辖域 ‖ 反证二读数 ‖ 写盘预检窗口）。

## 四、正形四条

1. 凡「外部命令输出先落文件、再由另一条式子判读」的**两段式**，语种要在**产出那一侧**固定（在产出那一行加 `LC_ALL=C` 前缀），★不是在判读那一侧写一条兼容多语种的正则***——后者每换一种语言就要改一次，且改的是副本不是源头。
2. ★固定语种只加在调用那一行，绝不顶层 `export LC_ALL=C`***（在册教训：顶层会把 python 的 stdout 编码跟着变成 ascii、中文 print 全炸）。
3. ★判据件凡跨面（容器／宿主）必须两面各跑一次***；只在一面验过＝未证，本例就是这一条的实证。
4. ★看见「非 OK 数＝总数」这种读数，先问一句：是它全坏了，还是我认不出它好了***（与坑91 本体「真没扫还是扫了没认出来」同一问；本例答案是「扫了、也认了、认错了方向」）。
