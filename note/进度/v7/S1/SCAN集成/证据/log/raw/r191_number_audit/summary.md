## 七、面条件（本次最重要的一条新方法事实）

`git archive` 只收 **git 收录的**文件；而 VCC 把每条引用**回整棵树**解析目标在不在位。本仓的 `.gitignore` 把 `opt/upstream/` 整片挡在外面（当场可核：`git check-ignore -v` 报的是 `.gitignore` 里那条 `opt/upstream/` 规则；`git ls-files --others --ignored --exclude-standard` 数出忽略件 6519 条，仅 `opt/upstream/lvr2/` 一处就 1582 件），
其中就有在册那条伪红的真身 `opt/upstream/lvr2/CMakeLists.txt`（984 行）。⇒ **只用 git 还原创者当时的工作树，RED 列会凭空多 3 条"路径失效"**
（实测六档变 8／7／3／2／1／1，多出的三条全落在同一条 lvr2 指针上；把那一件补回面，六档立即逐字回到 5／4／1／1／1／1）。

三条要记的：
1. **可复现性不只在"件版本＋文档内容"两轴上，还在"工作树里未被 git 收录但在位的文件"这第三轴上。**
2. 因此 A25 若签乙案，"定标留名"要连**面怎么取**一起留名（哪个提交、忽略件补没补、件版本），否则换个人复跑就对不上。
3. 这条属**候补闸读数的可复核性**，不动任何判定本体；要不要把它做成件自报的一格（面条件行）＝已排进待办 #83，按在册规矩**挂 A32 待追认、不自入门禁**。
