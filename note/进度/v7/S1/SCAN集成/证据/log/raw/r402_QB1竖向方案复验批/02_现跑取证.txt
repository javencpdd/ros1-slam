[3] 问2 · 甲′ 验收式"URDF 逐字 diff 空"是否可判（★亲验，副本在容器 /tmp）
====================================================================
# 建甲′ 副本（只加两个 property，第55行 origin 改用变量）：
#   <xacro:property name="lidar_z" value="0.38"/>
#   <xacro:property name="lidar_pitch" value="0"/>
#   <origin xyz="0 0 ${lidar_z}" rpy="0 ${lidar_pitch} 0"/>
$ rosrun xacro xacro orig.xacro > orig.urdf          ORIG_EXPAND_RC=0
$ rosrun xacro xacro jia_prime.xacro > jia_prime.urdf JIA_EXPAND_RC=0
$ wc -c orig.urdf jia_prime.urdf  -> 均 7786
$ diff orig.urdf jia_prime.urdf
3c3
< <!-- |    This document was autogenerated by xacro from orig.xacro                     | -->
---
> <!-- |    This document was autogenerated by xacro from jia_prime.xacro                | -->
DIFF_RC=1（非空）           ⇒ 唯一差异＝xacro 头部横幅注释里的“源文件路径”本身
$ md5sum orig.urdf jia_prime.urdf -> 5d6bb67… vs 68d69a2…（因横幅不同而不同）
# 同底名再验（把两内容放进 a/x.xacro、b/x.xacro 各展开）：横幅记录“调用路径”a/x.xacro vs b/x.xacro
$ diff a/x.urdf b/x.urdf -> 3c3 仍只差横幅路径 SAME_NAME_DIFF_RC=1
# ⇒ 逐字 diff 空 在“两个不同文件”间物理上做不到（横幅必带源路径）。
# 可判替代式：展开后仅排除 xacro 横幅行，再 diff ⇒
$ rosrun xacro xacro orig.xacro      | grep -v 'autogenerated by xacro' > orig.body.urdf
$ rosrun xacro xacro jia_prime.xacro | grep -v 'autogenerated by xacro' > jia_prime.body.urdf
$ diff orig.body.urdf jia_prime.body.urdf  -> BODY_DIFF_RC=0（逐字全等）
$ md5sum orig.body.urdf jia_prime.body.urdf -> 均 b812bdd560b6d16a…（同一）
# 展开确定性（无时间戳）：同文件连跑两次
$ rosrun xacro xacro jia_prime.xacro > t1.urdf; rosrun xacro xacro jia_prime.xacro > t2.urdf; diff t1 t2
REEXPAND_DETERMINISTIC=yes（唯一非确定项＝源路径横幅，非时间戳）
⇒ 结论：甲′“行为不变”这一实质为真（body 逐字全等），但“URDF 逐字 diff 为空”这条验收式按字面不可判，
  必须改写为“排除 xacro 横幅行后 diff 为空（或两侧以同一源名/同一路径展开后 diff 为空）”。

[4] 问2 附带 · 乙 的 pitch 落位与“度/弧度”施工雷（★自造项，副本在 /tmp）

# 乙案：lidar_z=0.30（使 0.30+0.15=0.45）、lidar_pitch 表意 15°。xacro 属性→URDF rpy 单位＝弧度！
$ rosrun xacro xacro yi_literal15.xacro | grep origin（rslidar 关节）
    <origin rpy="0 15 0" xyz="0 0 0.3"/>          ⇒ rpy 落 15 *弧度*（≈859°，荒谬）＝错
$ rosrun xacro xacro yi_radians.xacro | grep origin
    <origin rpy="0 0.2617993877991494 0" xyz="0 0 0.3"/>  ⇒ 正确 15°（须 ${radians(15)}）
$ python3 -c "import math;print(round(math.radians(15),6))" -> 0.261799
⇒ az §3 乙写“lidar_pitch＝15°”，但 xacro/URDF rpy 单位是弧度；施工须写 ${radians(15)}（或 0.261799…），
  否则“改到 15°”会落成真·15 弧度。此为设计件未点明的执行雷。
