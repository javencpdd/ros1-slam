# R681／批331：三级楼梯场景→支撑图→规划全链（38 点、三次落面、两次转层）

更新时间：2026-10-26

## 1. 做了什么

现有 stairs 资产只有单块台阶（R680 实查），本片**自建三级楼梯世界**作为场景真源：地面（z=0）、踏步（z=0.18）、平台（z=0.36），每级 1.5×1.2 m，含两块相邻重叠区；`scene_map.py` 逐面核对世界几何后生成 `support_map`，`validate.py` 校验通过。

规划节点按该图出路径，检查器逐点核验「落在某级足迹内且高度与该级 z 相符（±0.06 m）」。

| 项 | 读数 |
| --- | --- |
| 路径点数 | 38 |
| 分段 | 3（ground / step1 / landing） |
| 转层 | 2（ground→step1→landing） |
| 路径长度 | 4.114 m |
| 逐点落面与高度 | 全部通过，`bad=[]` |

## 2. 反例

把 `ground→step1` 的 `max_step_height_m` 从 0.2 调到 0.05（相对 0.18 m 实际高差超限），`validate.py` 当场拒绝并报 `E_MAP_EDGE_Z`——单步高差不能超过声明上限。

## 3. 边界

- 本片的「高程」来自**场景声明的支撑面高度**，不是真实高程观测；`deeprobotics_local_height_map` 13 份正式源仍缺失（R623），真实高程→support_map 链路单列任务 #139。
- 楼梯为自建最小场景，非正式 stairstudy 多级世界；跨场景矩阵仍待补。
- 未改第三方、未 push。证据：[sim_R681](sim_R681)。
