# R685／批335：#140 收口——move_base 侧拒绝分支返回失败而非空成功

更新时间：2026-10-26

## 1. 读数

| 项 | 值 |
| --- | --- |
| 目标 | 图外点 (99, 99, 9) |
| `/move_base/make_plan` 响应 | 只有 header 的 1 个 seq，**0 个 pose** |
| 插件日志 | `[v8 planner] planner refused or returned no path` |
| 服务侧理由 | `E_PLAN_GOAL_INVALID`（前批 R674 已取） |

即：move_base 侧拿到的是**空路径＋失败**，不是「SUCCESS 但空路径」。这条正是 R674 抓到的「绿灯空路径」在消费端的对偶。

## 2. 意义

插件 `makePlan` 的空路径判据（`poses.empty() → return false`）在真实 move_base 进程内生效：拒绝不会被包装成成功。

## 3. 边界

- 本片未测取消（cancel）路径：`make_plan` 是同步服务，move_base 侧取消语义要走 action，属另一条链。
- 未改第三方、未 push。证据：[sim_R685](sim_R685)。
