## 2. 本轮根因（此前一直零速的真因）

`rosparam set /follower/path "[[1.0, 0.0], [1.0, 0.5]]"` 这种 CLI 传入在容器里**没落到参数服务器**，节点 `get_param` 拿到空表 → `waypoints=0` → 一直零速。改用 `rosparam load` 的 YAML 后，节点打印 `raw=[[1.0, 0.0], [1.0, 0.5]]`、`waypoints=2`，一次跑通。

同时修掉三处真缺陷：同话题重复订阅、缺 `main` 入口、参数无默认值。
