# R688／批338：直发 /cmd_vel 能驱动 Gazebo 底盘（x: 0→1.013）

更新时间：2026-10-26

## 1. 决定性读数

在同一个容器、同一个 `flat.world`、同一个 spawn 出来的 `lite3` 模型下，**绕过整条链**直接：

```
rostopic pub -r 10 /cmd_vel geometry_msgs/Twist '{linear: {x: 0.3}}'
```

5 秒后 `/gazebo/model_states` 里 `lite3.position.x = 1.013`（起点 0）。

结论：**Gazebo 世界、机器人模型、`lite3_planar_drive` 插件、`/cmd_vel` 话题**这一段是通的，底盘对速度命令有真实响应（存在启动/仿真时间损耗，5 s 未到理论 1.5 m）。

## 2. 因此 #136 的问题被缩小

R687 里位移为 0，不是「底盘不动」，而是 **mux 之前那一段**（follower 是否发布、mux 是否把该源判为活跃）。下一步只需在同一窗口里 print `follower.log`、`mux.log` 与 `/follow/cmd_vel` 是否有非零值，即可定位。
