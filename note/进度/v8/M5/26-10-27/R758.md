# R758／批407：freeze 流程接入 loosening 基线（R751 P2-2）

更新时间：2026-10-27

## 1. 改动

R751 复核指出 `check_loosening` 全仓只有测试调用、`freeze` CLI 从不执行它，首次/后续冻结都可绕过 unfreeze。本批：

1. 新增 `BASELINE_FILE = calibration/frozen_baseline.json` 与 `freeze_guard(config, baseline_path=None)`：
   - 无基线文件＝首次冻结，放行（返回 `[]`）；
   - 基线存在时对 `FROZEN` 跑 `check_loosening(previous, current)`，未授权放宽抛 `E_CAL_LOOSENED`；
   - 基线不可读/缺 `frozen` 对象 → `E_CAL_BASELINE`（fail-closed）。
2. `calibration.py freeze` 在 `validate_frozen`＋`assert_digest` 之后调用 `freeze_guard(FROZEN)`；仅当 `freeze_allowed=True` 时写基线（含 frozen 快照、digest、version）；输出 JSON 增 `baseline` 字段。
3. 测试 48→**52**：无基线首冻放行、基线存在且下调 0.90→0.80 抛 `E_CAL_LOOSENED`、同配置放行、坏基线抛 `E_CAL_BASELINE`。
