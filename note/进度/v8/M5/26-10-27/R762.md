# R762／批411：第二定位后端设计面意见（根因＝先验图远端缺北墙）

更新时间：2026-10-27

## 1. 结论（设计面只读，独立实例）

1. **0.194 m 在当前先验图下不可达**，不是门/阈值/预测调参问题。9/9 run 在**掉头前远端**（gt_x>3.9、|yaw|<5°）的 aligned 误差已是 **0.249—0.270 m**（raw 0.178—0.200），此时尚未进入掉头；最好的 run 也只有 0.392。
2. **根因是地图覆盖缺口**：场地先验图 `venue_prior_185k.pcd`（sha `059ae0…`）与 m1 同坐标（六个体积障碍处都有 2k—5k 点），但**北墙条带在 x≈4.0 之后无点**（x=4.0—4.5 仅 5 点，x>4.5 为 0），而 m1 世界北墙到 **x=7.02**；路线掉头点正在 **x=4.186**，扫描看到约 3 m 未建图北墙。
3. **掉头错锁是沿 x 弱约束的次生现象**：实测滑步 0.14—0.29 m/帧、连续 3—4 帧，全部低于 0.35 m 单帧门；近端掉头（图完整处）同算法只有 **0.065—0.160 m**——同一节点、同一门、同一掉头速率，近端好远端坏，矛盾指向远端图。
4. **score 不能当判据**：最差样本 score 0.029—0.032、p50 0.008；错位姿反而分数更低（当前图下“保持位姿分数比较”会被反噬）。
5. **正确顺序**：先补图/换图并做 P2 的图-vs-GT 审计，再上运动学钳制＋IMU 陀螺；Scan Context/换后端只服务 P3 重定位，不解决 P2 连续跟踪误差。
