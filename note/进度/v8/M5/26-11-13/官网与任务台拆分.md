## 2. agent 白名单硬化（host-only，不挂 socket）

- 启动 `validate_stacks()`：容器必须 ∈ `{ros1-slam-sim-viz, ros1-slam-ros1}`；
  `cmd` 禁 shell 元字符（`; \` $ | > < & ( ) { }`）；不合规拒绝启动（rc=2）。
- `start/stop` 追加审计行到 `/tmp/v8-console/audit.log`（时间、client、动作、栈、结果、消息）。
