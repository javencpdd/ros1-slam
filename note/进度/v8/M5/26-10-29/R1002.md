# R1002 · 2D 消费适配：PGM→OccupancyGrid 与多图 provider grid topic

- 时间：2026-10-31 05:38—05:40 CST（qoder）；性质＝2D provider 消费面
- 依据：R1000 2D occupancy_grid 只读且仅 JSON，无 ROS 栅格主题；本批补 PGM 适配。

## 一、实现

- 新增 `representation/occupancy_adapter.py`：
  - 读取 P5/P2 PGM（注释、maxval、尺寸校验）；
  - 按 map JSON 的 `resolution/origin/frame/extent` 生成 OccupancyGrid 数据；
  - PGM 行翻转为 ROS bottom-up；阈值 0/254/其他 → occupied/free/unknown；
  - 非 occupancy_grid、extent 不匹配、坏头/坏体均失败。
- `multi_map_node` 对 2D 图发布 latched `/v8/maps/<id>/grid`（nav_msgs/OccupancyGrid）；
  PGM 缺失/失败只在 `status.grids` 记录错误，不影响 3D 图。
- `multi_map_smoke` 新增 map_c 2D 图与临时 PGM。

## 二、读数

- map_c：100×100、data=10000、occupied=20、resolution 0.1；`/v8/maps/map_c/grid` 实际收到。
- 三图版本 initial [2,2,1] → map_a delta 后 [3,2,1]；重启恢复 [3,2,1]，重放 map_a 仍 3。
- 2D 图不参与 delta（`E_MAPSERVICE_UPDATE_SCHEMA`，R1000）；grid 只读。
- 测试：`occupancy_adapter` **3/3**；V8 全树 **62 套件 0 失败**。

## 三、边界（如实）

- PGM 必须存在且尺寸匹配 map `extent`；本批 smoke 的 PGM 是临时生成样本，
  不是生产底图。
- 语义地图 schema/消费未实现；2D grid 无增量更新；`multi_map_node` 的 JSON latch
  与 grid 主题是两套消费面，尚未做版本联动订阅。
- 不改 map/delta 契约或判据；A1—A7 仍 `NOT_VALIDATED`。

现有 2D 导航图的 map 端口。
