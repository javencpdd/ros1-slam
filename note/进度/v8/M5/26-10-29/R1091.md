# R1091 · V8-X1 源保真回放与顶部保持：R1082/R1089 作废原因＝回放用了平地 XML

- 时间：2026-11-01 18:16—18:33 CST（qoder）；性质＝回放保真修复＋顶部保持重做
- 代码：`fcf8a0f5`（bridge/replay/top_hold 及测试）
- 证据：`evidence/R1091/`（旧/新两条源轨迹的全量回放、500 行恢复校验、三变体保持、
  source_config、command、code_ref、tests、41 份文件 hashes）

## 一、根因

R1082/R1089 的回放器默认用 `/tmp/mjcf/Lite3.xml`，那是**平地模型**；源运行
`a5_v8x1_runtime.py` 通过 `walk.make_stairs_xml` 生成的是 5 级台阶世界
（`stairs.xml`）。源轨迹在 x≈1.1 m 后进入台阶，平地回放从 tick177 起必然分叉，
随后跌落/`action_nonfinite`。所以：

- R1089 的“回放不复现源轨迹”**不是**执行器/策略不确定，而是回放世界错了；
- R1082 的“零指令顶部跌落”同样是在平地上测的，**结论作废**。

## 二、实现

`a5_v8x1_bridge.py`：

- trace 新增每 tick `qacc_warmstart`（MuJoCo 接触求解 warmstart）；
- 新增 `--replay-start-index N`：从第 N-1 行恢复 qpos/qvel、sim_time、warmstart；
- 新增 `resume_history(rows, N)`：按源 trace 重建最后 5 帧观测与 `last_action`，
  非有限动作按源桥行为跳过并清零 `last_action`。

`a5_v8x1_replay.py`：透传 start-index，输出 `source_comparison` 与
`replay_comparison`；`--skip-source-compare` 供追加行（保持段）使用。
`a5_v8x1_top_hold.py`：新增源世界 `--xml`，从源末端恢复后只跑追加保持段。

## 四、结论与边界

- **R1082 的零指令顶部跌落结论作废**（原因另起：回放平地模型）；
  **R1089 的“回放不复现源轨迹 / top finish OPEN”作废**（原因另起：同一 XML 错误）。
- 在“源轨迹末端 + 同一台阶世界 + 追加零/斜坡/前馈”这一窄口径下，顶部保持
  **PASS**；这是 V8-X1 顶部收尾的首个成立证据。
- 仍 **不** 据此升格 V8-X1/A5：单 seed、开环回放、无 ROS 重规划、无 Gazebo/
  真机；没有重新训练策略，也没有改 #151 formal 两键。
- 下一步：多 seed/多源轨迹重复；在在线 ROS 链上复现同一保持；再谈 A5 物理跨层
