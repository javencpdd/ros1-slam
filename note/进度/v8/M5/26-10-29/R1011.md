# R1011 · 外部 nodelet manager：`nodelet_group` 组件与真实冒烟

- 时间：2026-10-31 14:44—15:05 CST（qoder）；性质＝plugin 托管第二形态
- 依据：README 未接项含“外部 nodelet manager”；hdl 等组件由 manager + 多个 load 承载，standalone 不够。

## 一、实现

- manifest `launch.kind=nodelet_group`：宿主 `package` 固定 `nodelet`，`manager` 可选
  （缺省 `<instance>_manager`），`plugins` 为非空列表，每项 `{type: pkg/Class, name?, params?}`。
- 预检：宿主 executable `nodelet` 在包索引；每个插件包存在、类在 `plugin_classes`（若声明）。
- 渲染/运行：生成 manager 节点 + 每插件一条 `nodelet load <type> <manager> --no-bond`；
  插件参数按插件节点名写入，hosted nodelet 读取；namespace 同时作用于 manager/loader。
- `runtime.default_command` 生成临时 launch（`/tmp/v8_nodelet_group_*.launch`）交 roslaunch，
  ProcessRunner 组信号停整棵进程树。
- 真实冒烟 `nodelet_group_smoke.py`：manager `/v8_group/v8_group_mgr` + Plus `/v8_group/plus`，
  参数 2.5、输入 3.0 → 输出 5.5。

## 二、读数

- framework **28/28**、runtime **11/11**；V8 全树 **63 套件 0 失败**。
- 冒烟：value_param=2.5、output=5.5、节点列表含 manager/plus、停止后无存活进程。
- 探针：roslaunch 形态可装载；`nodelet standalone`/`load` 均忽略 remap 参数（topic 随节点名）。

## 三、边界

- 只支持 nodelet 宿主；不解析 pluginlib XML、不验证类实现，仅静态 `plugin_classes`。
- 临时 launch 不回收；remap 不承诺（实测被 nodelet 忽略），端口 topic 需与真实名一致。
- 无 bond（loader 固定 `--no-bond`）；manager 的 required/launch-prefix 未暴露。
- 未改 A1 判据；A1—A7 仍 `NOT_VALIDATED`。
