# R961 · F4 MapDelta：基版本、幂等重放与原子增量提交

- 时间：2026-10-31 00:45—00:52 CST（qoder）；性质＝地图增量事务（F4），不启 ROS
- 依据：27 号补丁 F4；局部缓存按周期提交增量，全局地图原子合并。

## 一、改动

1. 新增 `contracts/schema/map_delta.v1.json`：`map_id/base_version/delta_id/source/ops`，
   ops 支持 `upsert_surface`/`remove_surface`；`validate.py` 增语义检查（upsert 带 surface、
   remove 带 surface_id）。
2. `MapService` 增 `propose_delta`：
   - `delta_id` 幂等：同 id 同内容返回当前版本、不重复升版；同 id 异内容
     `E_DELTA_REPLAY_CONFLICT`；
   - 旧/新 base 与当前版本不一致 → `E_MAPSERVICE_STALE`（重放先于 base 检查）；
   - 先在副本上应用并过 map 契约，成功后才升版；失败不改 `current`、不写 history；
   - 升版写 `source.uri/sha256`，并通知订阅者；`E_DELTA_NO_CHANGE` 拒绝空 delta。
3. 7 项测试：升版/通知、重放幂等、同 id 异内容、旧 base/未知删除、非法结果原子性、
   删除被引用面、无变化。
