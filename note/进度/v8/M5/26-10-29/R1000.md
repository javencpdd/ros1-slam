# R1000 · 多图 schema 选择：2D occupancy_grid 只读、support_map 可更新

- 时间：2026-10-31 05:32—05:34 CST（qoder）；性质＝schema 感知的 MapRouter 切片
- 依据：R998/R999 多图 provider 只承载 support_map；本批允许 2D occupancy_grid 共存。

## 一、实现

- `MapService`：
  - 非 `support_map` 的 delta 一律拒绝（`E_MAPSERVICE_UPDATE_SCHEMA`）；
  - 非支撑图的净空/查询拒绝（`E_MAPSERVICE_UNSUPPORTED_KIND`）；
  - 证据摘要对非支撑图返回 `{'state':'not_applicable','kind':...}`，不假设 `surfaces` 存在。
- `MapRouter`：新增 `select(kind)`；`snapshot/status` 带 `kind`。
- 2D `occupancy_grid` 与 3D `support_map` 可同目录持久化、重载；2D 只读、3D 可 delta。

## 二、读数

- 同目录 `flat_two_boxes`（occupancy_grid）+ `map_a`（support_map）：
  - `select('occupancy_grid')=['flat_two_boxes']`，`select('support_map')=['map_a']`；
  - 2D delta → `E_MAPSERVICE_UPDATE_SCHEMA`；support map_a delta → v2；
  - 重载后 kind/version 保持：flat v1、map_a v2。
- 测试：`map_router` **4/4**；V8 全树 **61 套件 0 失败**。

## 三、边界（如实）

- 2D occupancy_grid 目前只读（无 delta/净空 API）；语义地图 schema 未实现。
- `multi_map_node` 的 ROS 订阅仍以 support 图 delta 为主；2D 只作为可查询 latch，
  尚未加 nav_msgs/OccupancyGrid/语义消费适配。
- 不改 map/delta 契约或判据；A1—A7 仍 `NOT_VALIDATED`。

## 四、下一件

把 2D/semantic 的消费适配接到 provider/图（或为多图 provider 加分 schema 的 ROS 类型），
再决定是否扩展 delta 契约。
