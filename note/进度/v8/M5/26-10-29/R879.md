# R879 · MuJoCo 仿真可视化：宿主 X + GPU viewer 跑通

- 时间：2026-10-29（qoder）；任务卡 `T-20261029-02` / `T-20261029-01`；性质＝可视化（无真机）
- 状态：MuJoCo viewer 在宿主桌面打开（`MuJoCo : Lite3`，1706×960）；ROS1 桥同进程运行

## 一、做法

- 给 `mj_ros_bridge.py` 增 `--viewer`：`mujoco.viewer.launch_passive(model, data)`，每拍 `sync()`，
  退出时 `close()`；其余话题逻辑不变。
- 在 `sim-viz` 容器（有宿主 X 与 NVIDIA 透传）里跑桥＋viewer；运行时从 v8codex 复制到
  `/tmp/mjviz`（numpy 1.24.4 + numpy.libs + mujoco 2.3.7 + glfw + onnxruntime 1.16.3）。
- 宿主 `xhost +si:localuser:root`；桥期间发 `/cmd_vel` 0.2 m/s ×6 s。

## 二、GPU 矩阵（容器）

| 容器 | GPU 设备 | 渲染器 |
|---|---|---|
| `ros1-slam-sim-viz` | `nvidia-smi` 可见 RTX 2060 SUPER / 580.178.04 | glxinfo = **NVIDIA GeForce RTX 2060 SUPER/PCIe/SSE2** |
| `ros1-slam-sim` | 无 nvidia-smi（未申请 GPU） | — |
| `v8codex-20261028` | 无 nvidia-smi | — |
| `my_foxy_env` | 无 nvidia-smi | — |

- viewer 运行期间读到 GPU：**utilization 33—35%、memory 2501 MiB / 8192 MiB**（含桌面）。
- 容器内 `nvidia-smi` 的 Processes 表显示 "No running processes found"（PID 命名空间/图形客户端不可见），
  因此不能拿进程表当 viewer 的 GPU 归属证据；可证的是：容器内 `glxinfo` 为 NVIDIA 硬件渲染，
  且 MuJoCo viewer 用的是同一 X/GLX 显示。

## 四、边界

- 可视化只读同一 MuJoCo 状态；不改变物理/判据。PPO 仍平地策略。
- viewer 跑在 `sim-viz` 的 `/tmp/mjviz` 外挂运行时上，不是镜像内置；换机需按 command.txt 重建。
- GPU 利用率是整卡读数（含桌面），不能当作 viewer 独占性能指标。
