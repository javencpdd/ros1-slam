# R1004 · 语义地图独立契约：semantic_map/v1 校验、只读目录与 ROS 发布

- 时间：2026-10-31 13:42—13:46 CST（qoder）；性质＝地图层新增语义扩展
- 依据：README 目标把语义地图列为可接入地图；`map.v1`/A1 已冻结，语义不能并入其 schema。

## 一、实现

- 新增 `semantic_map/v1`：`map_id`（小写/数字/下划线）、`map_version>=1`、`frame`、
  `features`；每要素含唯一 `id`、`kind` 与四类几何之一：`point`/`line`/`polygon`/`box`。
- 校验 fail-closed：schema、map_id、版本、frame、重复要素 id、kind、几何点数/有限值、
  box 上下界、attributes 类型；`load()` 对坏 JSON 报 `E_SEMANTIC_JSON`。
- `SemanticCatalog` 只读装载多图，重复 `map_id` 拒绝（`E_SEMANTIC_DUPLICATE`），
  `status()` 返回逐图 kind 计数。
- `semantic_map_node`：`~semantic_files` 逗号分隔；逐图 latch 发布
  `/v8/semantics/<id>`，`/v8/semantics/status` 汇总，逐图 Trigger 查询；只读、不接 delta。
- `semantic_map_smoke`：真实 ROS 双图（sem_a v2 point/line、sem_b v1 box/polygon），
  验证发布、查询、状态，以及重复 map_id 启动即拒绝。

## 二、读数

- smoke：sem_a v2 features=2 kinds=[line,point]；sem_b v1 features=2 kinds=[box,polygon]；
  query sem_b `{map_id:sem_b,frame:map,features:2}`；status 两图 summary 正确。
- 重复文件：节点 rc=1，stderr 含 `E_SEMANTIC_DUPLICATE`。
- `test_semantic_map` **5/5**；V8 全树 **63 套件 0 失败**。

## 三、边界

- 语义层独立于 `map.v1`，不写 `MapService`/`MapStore`，不参与 A1 冻结判据。
- 只读：无 delta/版本推进/消费者联动；未接规划或 costmap。
- 四类几何仅做坐标与结构校验，不做语义推理、不替代占据/支撑证据。
- A1—A7 仍 `NOT_VALIDATED`。
