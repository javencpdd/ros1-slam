# R1029 · 选配器组合级校验：整组选择先过图与安全门

- 时间：2026-10-31 21:30 CST（qoder）；性质＝选配器组合校验闭环
- 依据：selector 只对单实例替换做 graph.check+safety 预检，整组选择要等导出后
  再由 CLI 检查；README「开发中」仍列「selector 组合级校验」。

## 一、实现

- `selector.combination(graph, catalog, choices)`：对整组替换一次执行
  `graph.check`、`render.render_plan`、`safety.check_plan`；未知实例/组件、
  角色签名不匹配分别返回 `E_SELECT_INSTANCE`／`E_SELECT_COMPONENT`／
  `E_SELECT_ROLE`，图/安全失败透传理由码与 detail。
- CLI 新增可重复 `--choose instance=component` 与 `--out-selected`：
  组合不合法时打印理由并 rc=5、不写 HTML/选配图；合法时把组合摘要写入
  `--out-json` 并写出选配图。原单实例矩阵与 HTML 行为不变。

## 二、读数

- `test_select` **5/5**（新增组合通过、2D/3D 维度失败、三类选择错误、
  CLI rc 0/5 与导出）。
- CLI 合法组合：rc=0、digest `8c9931d5…`、命令写者
  `/cmd_vel=mux`、`/cmd_vel_advice/local=local`，选配图写出。
- CLI 非法组合（local→local3d）：rc=5、`E_GRAPH_DIMENSION`
  （global.path 2D → local 3D），不写 HTML。
- V8 全树 **65 套件 0 失败**。

## 三、边界

- 组合校验仍是静态图/安全门，不启动进程、不验证运行行为；参数与配置
  兼容性仍由 `graph.check` 既有规则决定。
- HTML 页面的交互仍是单实例预检，组合以 CLI/`--out-json` 为准。
- A1—A7 仍 `NOT_VALIDATED`。
