# R1033 · 定位位姿交接：一致即无缝切源，跳变则拒绝

- 时间：2026-10-31 22:00—22:20 CST（qoder）；性质＝定位链安全交接（合成源）
- 依据：README「未实现」列「命令/定位链零中断热替换」；命令侧只有安全 hold
  （R1020），定位侧没有切源门。

## 一、实现

- `pose_mux.py`：双路位姿源（a/b）+ 选择。切源要求目标源新鲜且与最近输出
  距离 ≤ `max_gap_m`；激活源单帧跳变同样拒绝（`E_POSE_MUX_JUMP`），避免
  坏源直接穿透；源过期 `E_POSE_MUX_STALE`，未就绪 `E_POSE_MUX_NOT_READY`。
- `pose_mux_node.py`：订阅两路 PoseStamped 与 String 选择，按 `rate_hz` 持续
  发布 `/v8/local/pose`，状态只在变化时发布；非 `map` 帧拒绝。
- 组件/图：`v8.fw.pose_mux`、`graph_pose_mux`；preflight 增加注册与渲染断言。

## 二、读数

- pose_mux 单测 **3/3**、preflight **9/9**；V8 全树 **68 套件 0 失败**。
- 真实 ROS 交接：一致源（差 0.05 m）切源被接受；20 Hz 流在切换处最大输出
  间隔 **52.6 ms**（无中断）；目标源跳变 4.95 m 被 `E_POSE_MUX_JUMP` 拒绝，
  末值仍为旧源 **0.05**；停止退净。

## 三、边界

- 两路位姿为冒烟合成源，不是真实定位算法（hdl/faster_lio）之间的切换；
  坐标系一致性与时间同步仅按 `map` 帧与新鲜度检查。
- 阈值 `max_gap_m`/`max_age_s` 是组件参数，未进入冻结判据；A1—A7 仍
  `NOT_VALIDATED`。
