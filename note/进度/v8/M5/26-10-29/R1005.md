# R1005 · plugin 托管：nodelet standalone 组件与零命令图装配

- 时间：2026-10-31 13:47—13:55 CST（qoder）；性质＝框架未接入项 #1 收口
- 依据：manifest v2 schema 早留 `kind: plugin` 枚举，但 config 明确拒绝；hdl 等 nodelet 算法只能走 include，图中无法配参数/端口。

## 一、实现

- `kind: plugin` 约定：宿主 `package` 固定 `nodelet`，`type` 为 pluginlib 名 `pkg/Class`；
  不接受 `launch_file`/`param_files`/`args`，支持 `remap` 与实例 `config`。
- 预检：宿主包须在包索引且含 `nodelet` 可执行；插件包（`type` 前缀）须在索引；
  type 必须恰为两段非空。缺项分别报 `E_CFG_LAUNCH`/`E_LAUNCH_TYPE`/`E_LAUNCH_PACKAGE`。
- 渲染：`<node pkg="nodelet" type="nodelet" args="standalone pkg/Class">`，config/params/remap 同 node。
- 运行：`rosrun nodelet nodelet standalone pkg/Class __name:=<instance> __ns:=<namespace>`
  + `_key:=value` 私有参数；实例 id 做 ROS 名清洗。
- 安全接线：无任何 `command_topic` 的只读/插件图允许启动（`command_owner=null`）；
  一旦存在命令话题，仍要求唯一 `/cmd_vel` 写者且为 `safety_arbiter`，建议边规则不变。

## 二、读数

- 探针：`nodelet standalone nodelet_tutorial_math/Plus __name:=plus __ns:=/v8_plugin_smoke
  _value:=2.5` → 节点 `/v8_plugin_smoke/plus`、param 2.5、topic `in/out`、输入 3.0 输出 5.5。
- 真实冒烟：graph `plugin_nodelet_plus` 经 check/plan/Assembly 启动；startup_order `[plus]`，
  `command_owner=null`，`value_param=2.5`，3.0→5.5，停止后进程退净（空进程表）。
- 测试：framework **26/26**、runtime **8/8**、safety **8/8**；V8 全树 **63 套件 0 失败**。

## 三、边界

- 只支持单进程 `nodelet standalone`；不支持外部 manager、`nodelet load`、bond 与多 nodelet 同宿。
- 只校验包索引声明，不解析 pluginlib XML、不验证类是否可加载；真实类可用性由启动期暴露。
- SIGTERM 停止不执行 ROS shutdown，master 可能残留注册（实测节点已退净）；不以
  `getSystemState` 残留判失败。
- 不改 `map.v1`/A1 判据；A1—A7 仍 `NOT_VALIDATED`。
