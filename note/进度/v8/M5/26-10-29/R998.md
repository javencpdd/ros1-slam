# R998 · 多图 ROS provider：map_id 路由、逐图 latch 与查询

- 时间：2026-10-31 05:26—05:29 CST（qoder）；性质＝真实 ROS 多图 provider 冒烟
- 依据：R997 MapRouter 只有纯核心；本批接入 ROS 发布/查询并验证重启恢复。

## 一、实现

- 新增 `representation/multi_map_node.py`：
  - 启动时读取 `~map_files`（逗号分隔）与 `~state_dir`，用 `MapRouter` 建立每图状态；
  - 订阅 `~delta_topic`（默认 `/map_delta`），按 `delta.map_id` 路由；
  - 每图 latched 发布 `~topic_prefix/<map_id>`（默认 `/v8/maps/<id>`），状态发布
    `/v8/maps/status`；每图 `Trigger` 查询 `/v8/maps/<map_id>/query`；
  - 坏 delta/未知图只记 status，不改变任何地图。
- `multi_map_smoke.py`：真实 master 11470，两份 fixture（map_a/map_b，初始 v2）；
  发 map_a delta → v3；重启节点后恢复 v3/v2；重放同 delta 仍 v3。

## 二、读数

| 项 | 值 |
| --- | --- |
| 初始版本 | map_a 2 / map_b 2 |
| delta 后 | map_a 3 / map_b 2 |
| map_a 查询 | Trigger 返回 v3 |
| status applied | map_a=1 / map_b=0 |
| 重启恢复 | map_a 3 / map_b 2 |
| 重放 | map_a 仍 3（幂等） |
| 测试 | multi_map_node 2/2、map_router 3/3、V8 全树 **61 套件 0 失败** |

- 两图版本/history/幂等表独立；topic 状态与 query 返回一致。

## 三、边界（如实）

- 本地多图 provider；没有跨图原子事务、并发写者、跨机复制、地图 schema 混合的消费端选择。
- 仍只处理 `map_delta/v1` 的支撑图；2D/语义地图需要各自 schema 的 provider 适配。
- 不改 map/delta 契约或判据；A1—A7 仍 `NOT_VALIDATED`；无真机/QNX。
