# R997 · MapRouter 多图路由：MapDelta 按 map_id 分发到独立 MapService

- 时间：2026-10-31 05:22—05:25 CST（qoder）；性质＝纯 Python 路由核心 + 持久化
- 依据：R989 `MapStore` 只有按图存储；本批把多图路由补到 delta 层。

## 一、实现

- 新增 `representation/map_router.py`：
  - `MapRouter(root, maps)`：每个 map_id 一个 `MapService`，优先从 `MapStore` 加载已有快照，
    否则 publish 初始地图并落盘；
  - `apply/apply_text`：按 `delta.map_id` 路由，成功后把对应服务原子保存；
  - `snapshot(map_id)/status()/ids()`：逐图视图；
  - 未知 map_id、坏 JSON、非对象 delta、重复初始 map_id 全部 fail-closed
    （`E_MAPSERVICE_MAP_ID` / `E_DELTA_JSON` / `E_DELTA_INVALID` / `E_MAPSERVICE_DUPLICATE`）。
- 版本、history、applied_deltas 各图独立；路由层不做跨图合并/事务。

## 二、读数

- `map_a` 收到 delta 后 v2、`map_b` 保持 v1；两文件 `map_a.json`/`map_b.json` 各自保存。
- 新 `MapRouter` 重载后 `map_a` 仍 v2、`applied_deltas=1`，`map_b` v1/0；
  重放同一 delta 仍返回 v2（幂等）。
- 未知 map_id → `E_MAPSERVICE_MAP_ID`；重复 add 已有 map → `E_MAPSERVICE_DUPLICATE`。
- 测试：`map_router` **3/3**；V8 全树 **60 套件 0 失败**（新增第 60 套）。

## 三、边界（如实）

- 只做本地路由核心；ROS provider 仍单 map_id，未接多图话题/服务。
- 无跨图原子事务、并发写者、跨机复制；地图 schema 混合时的消费端选择未做。
- 不改 map/delta 契约或判据；A1—A7 仍 `NOT_VALIDATED`。
