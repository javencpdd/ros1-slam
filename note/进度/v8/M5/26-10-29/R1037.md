# R1037 · 三维全局规划可取消：预搜索也响应取消

- 时间：2026-10-31 23:05—23:25 CST（qoder）；性质＝A4 取消分支运行时证据
- 依据：R1036 记录适配器未接取消，A4「无路/超预算/取消可区分」缺 cancel。

## 一、实现

- `support_planner.py`：取消谓词除 A* 弹出点外，还在净空/障碍过滤
  （每 128 格）、端点连接候选与跨面最近格对搜索（每 4096 对）轮询；
  预搜索阶段也能以 `E_PLAN_CANCELLED` 退出，不改变正常搜索结果。
- `topic_node.py`：规划移到后台线程；新增 Trigger `~cancel`；generation
  防止旧任务回写；取消后不发成功路径，只发状态与空 Path 清屏；
  规划启动时发 `E_PLAN_RUNNING`。
- manifest `cancellation: cooperative`；单测增加取消谓词用例。

## 二、读数

- adapter 单测 **4/4**、support planner **12/12**；V8 全树 **69 套件 0 失败**。
- 真实冒烟（10 s 级无路搜索）：cancel 后 **0.103—0.163 s** 返回
  `E_PLAN_CANCELLED`（detail `endpoint` 或 `portal search cancelled`）；
  `nonzero_paths_after_cancel=0`；停止退净。

## 三、边界

- 取消是协作式轮询，不能抢占单条 Python 语句；第三方/长阻塞 I/O 仍可能
  延迟响应。
- 只证明 cancel 分支可运行与可区分，不代签 A4；A1—A7 仍 `NOT_VALIDATED`。
