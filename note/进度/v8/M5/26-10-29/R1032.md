# R1032 · 语义障碍接入规划：绕行与移除后直行

- 时间：2026-10-31 21:40—22:00 CST（qoder）；性质＝语义障碍消费者闭环
- 依据：R1026 只把语义支撑面接入规划；README「未实现」仍列语义障碍/标签
  消费者。

## 一、实现

- `semantic_obstacle_bridge.py`：`role=obstacle` 的 box 转成规划器 obstacle
  JSON（`min`/`max`，可选 `velocity`、`stamp`、`active_from/until`）；非障碍
  要素忽略；非 box、空盒、坏向量/时间 fail-closed。
- `semantic_obstacle_bridge_node.py`：订阅语义地图，发布 latch 的 obstacle
  列表与状态（count/ids/map_version）。
- 组件/图：`v8.fw.semantic_obstacles`、`graph_semantic_obstacle_planning`
  （provider→support/obstacles 两消费者→真实 local_native）；preflight 增加
  双消费者绑定与启动序断言。

## 二、读数

- obstacle 单测 **4/4**、preflight **8/8**；V8 全树 **67 套件 0 失败**。
- 真实冒烟（ProcessRunner 按图启动四实例）：障碍在场时轨迹在 x 3.0—3.4
  区间的**最低 y=2.8**，避开膨胀受阻带 1.45—2.55，`arrived`。
- 语义 v2 移除障碍：obstacle 状态 count **1→0**；支撑图升到 v2，规划器
  重规划**直行**（带内最低 y=2.4）并 `arrived`；`changed=true`，停止退净。

## 三、边界

- 只接入障碍 box 这一种语义消费者；语义标签、语义代价与动态障碍预测器
  仍未接。
- 障碍膨胀沿用规划器 radius+clearance；语义层不额外膨胀。
- 语义更新由冒烟直接发布（provider 仍只读文件）；A1—A7 仍 `NOT_VALIDATED`。
