# R829／批478：承重接触体误判修正——小腿网格不再触地，点足模型下四步周期 27 相位全过

更新时间：2026-10-28

## 1. 发现：站立时承重的是小腿网格，不是足端球

用 `mj_contactForce` 逐接触点做体级归属（新入 `foot_normals()`，`CRAWL_CONTACTS=1` 开关），
站姿实测：

| 体 | 法向力（N/腿） |
| --- | --- |
| FL/FR/HL/HR_SHANK | **22.2 / 21.7 / 35.8 / 35.2** |
| FL/FR/HL/HR_FOOT（球 r=0.022） | 0.4 / 0.0 / 1.5 / 1.5 |

即该 MJCF 的小腿网格在标称站姿就压在地面上，足端球只是「陪着」——与真机（足端胶垫承受全部体重）
不符。此前 R822—R828 的滑移读数、以及「滑移与法向力分配有关」的假设都需要改写：
**接触体本身就不是足端**。

## 2. 修正

在 `MjModel` 内存里关闭所有 `*_SHANK` 体的 `contype/conaffinity`（第三方文件一字不动），
使足端球成为唯一地面接触。修正后站立接触力：**足端 20.7 / 20.0 / 37.9 / 37.4 N**（合计 ≈ mg）。

点足模型下原增益不再够用（机体下沉、抬腿只到 3.8—6.4 cm），重标：

- 支撑腿 `kp 150 / kd 1.0`（数值稳定域：`kd·dt/m ≈ 1.1 < 2`、`kp·dt²/m ≈ 0.33`）；
- 摆动腿 `kp 100 / kd 1.0`；
- advance 相位拆成两段 0.75 s 斜坡（末步单段推进曾把四足拖滑 13—26 mm）；
- 其余不变：drive 0.05、swing 0.04、margin_min 0.05、步序 FL→HR→FR→HL。

## 4. 另起句更正（R822—R828）

- R825/R826/R827 的「滑移 25—53 mm、与速度无关、疑三支撑足法向力分配」——**接触体判定错误**：
  那些读数是在小腿网格承重的模型上测的，滑移主体是小腿网格边缘而非足端球；
- R826「完整周期跑通」的结论在**该修正模型上不成立**（点足模型下同样参数 8 相位失败），
  R829 才是点足模型的通过读数；
- R822 的高度参考、R823/R824 的裕度门槛与闭环移重、R825 的横向回中，在点足模型下仍然有效
  （本件全部沿用）。
