# R808／批457：A2 停止链运行面首 cell——hold/恢复/源超时/清场

更新时间：2026-10-28

## 1. 做了什么

`regression/a2_stop_chain.py`：在真实 mux 上发 20 Hz `/follow/cmd_vel`，观测 `/cmd_vel`：
建立非零流 → 发 hold → 量归零时延 → 释放 hold → 量恢复 → 停发源 → 量超时归零；
另核 `/cmd_vel` 唯一写者与清场。未改任何配置。

## 2. 读数

| 非零流 | (0.2, 0, 0) |

判定 PASS。与冻结 `budgets.cancel_time_s`（0.108 s，scope=mux_hold_only）同量级，本 cell 只作运行面旁证，不改冻结值。

## 3. 边界

- 只覆盖 mux 通道（hold/源超时/单写者/清场），**不含** Gazebo 闭环与任务进程崩溃（A2 的「崩溃」事件仍缺）；
- 墙钟读数受 RTF 影响，仿真钟折算只作参考；
- 无宿主侧单测（该件是 ROS 测量脚本，靠运行面读数与清场核验把关）。
