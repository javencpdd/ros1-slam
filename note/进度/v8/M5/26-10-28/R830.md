# R830／批479：V8-X1 前腿落到 0.10 m 台阶面（点足模型）——抬升/前摆拆分是关键

更新时间：2026-10-28

## 1. 改动

1. **阶面落足目标**：新增 `--step-x / --step-h / --step-swing`。前腿（FL/FR）若本步摆动后的
   世界 x 会越过台阶前沿，则落足高度＝**阶高＋足端球半径**（0.10+0.022=0.122 m），
   x 前伸 `step_swing`；`place` 相位按该高度降落与判定（`land_z` 入记录，判据
   `|实际 z − land_z| ≤ 3 cm`）。
2. **抬升与前摆拆成两个相位**（R819 的结论在新模型上重验）：先竖直抬到「阶高＋抬升量」，
   再在高度上前摆 `step_swing`，然后降落。抬腿与前摆同时做时支撑足滑 7.3 cm，拆开后 3.6 mm。
3. 修正 `land_z` 记录早于判据（此前 place 判据读不到目标高度）。
