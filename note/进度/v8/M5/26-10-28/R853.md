# R853／批500：A1/A7 运行面 12 格矩阵——2 后端×真值/估计×3 场景，12/12 PASS

更新时间：2026-10-28

## 1. 新增能力

为了跑「双轨×后端」四组合，新增了**估计定位轨**（不是 LIO/NDT，是夹具）：

- `m1_gazebo.launch` 加 `map_to_odom` 开关（默认 true，向后兼容）；估计轨时关掉恒等桥，
  由 `regression/noisy_localization.py` 独占发 map→odom；
- `regression/estimated_track.py`：种子化、平滑、有界的偏移
  （**±0.05 m／±0.03 rad**），纯函数、无 ROS 依赖；
- `noisy_localization.py`：**50 Hz + 60 ms 前瞻戳**（见 §3 的坑），仿真时钟；
- `runtime_lab.py`：`--localization truth|noisy`、`--noise-seed`；manifest 写
  `track`／`localization_source`／`localization_track`／`seed_effect.estimated_track`；
- `runtime_batch.py`：同两选项，作业预登记带 `localization` 与 `noise_seed`；
- `driver.py`：结果带 `track`／`localization_source`／`localization_track`；
- 纯函数测试 `regression/test_estimated_track.py`（3 项：界、确定性/种子敏感、入参守卫）。

评价仍用 `/sim/odom_gt` 真值；估计轨只改导航栈的定位belief，不改评价。

## 3. 关键坑（首次估计轨 0/3 失败）

20 Hz 动态 map→odom 的最新戳比控制器请求落后约 13 ms，move_base 报
`Lookup would require extrapolation 0.013s into the future`，控制器拿不到局部规划、
DWA 反复恢复、机器人原地不动（最终 0.0 m）。处置：发布提到 **50 Hz** 并给
**+60 ms 前瞻戳**，此后 12/12 通过。静止桥没有这个问题（无时间戳外推）。

## 4. 边界

1. **单 seed（0）**、0.4 m/s、平地；不是设计层 48 cell／3 seed 的全矩阵。
2. 估计轨是**种子化 map→odom 偏移夹具**，不是 LIO/NDT，也不是传感器模型；
   真实双后端切换仍未验（A6 未动）。
3. 栈＝flat2d（map_server + 全局 GlobalPlanner + DWA/TEB + mux + Gazebo），
   评价位姿用真值 `/sim/odom_gt`；不含四足接触动力学、不含跨层、不含真机。
4. SC09 是 flat2d 替代场景（注入方块 g0），不是官方 SC09 物理验收。
5. 本件不改变冻结成功率的分母；12 格是 `runtime_experimental`。
