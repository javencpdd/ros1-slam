# R833／批482：V8-X1 stair 模式全序列——前段通过，后腿跨阶桥接仍失稳（三次尝试）

更新时间：2026-10-28

## 1. 改动

把 crawl 的单腿流程抽成 `do_step(cur_leg, tag, advance, swing, allow_step)` 与
`do_climb(dist, dz)`，新增 `stair` 模式：

```
settle → FL 落阶面 → FR 落阶面 → 机体上阶前移(climb1) → 后腿分步前移 N 轮（HL/HR 交替，
每步带推进）→ 后腿抬升（越过前沿时落到阶面）→ 终段前移(climb2) → settle
```

## 2. 正结果：前段（两前腿落阶＋机体上抬）两次复现

| 运行 | climb1 后机体 | 滑移 | 前足 |
| --- | --- | --- | --- |
| v1（drive 0.05、climb 0.15/0.05、后腿 3×0.10） | z 0.370 | ≤1.5 cm | FL/FR 在阶面 1.09 |
| v3（drive 0.04、climb 0.08/0.04、后腿 5×0.06） | z 0.374 | ≤1.2 cm | 在阶面 |

## 3. 负结果：后腿在跨阶桥接姿态下抬升

跨阶桥接＝两前足在阶面（z 0.121）、后足在地面（z 0.021）、机体横跨台阶立面。

| 变体 | 关键读数 | 结果 |
| --- | --- | --- |
| v1：起步 0.80，后腿 3×0.10，每步推进 0.05 | 首次后腿抬升支撑滑 **3.8 cm**；随后 place 滑 **13.7 cm**、advance 滑 14.6 cm；前足被拽回地面（1.09→0.87） | 未摔但 5 相位失败 |
| v2：起步 0.85（更靠近台阶） | **FL 抬腿即失败**（起步距前沿仅约 3 cm，竖直抬升位姿不可用） | 后续 climb 崩、摔 |
| v3：起步 0.80，后腿 5×0.06，推进 0.04 | FR 落阶滑移超限；后腿移重多次滑 2—13 cm，机体末位 (1.52,−0.29,0.18) | 摔（z 0.179） |

**共同特征**：后腿一离地，两前足（仅落在阶面内侧 8—9 cm）被拖向台阶外；支撑多边形在
三维上是「两高足＋一低足」，横向很小的扰动就产生大滑移。

## 4. 诊断与下一步（未完成）

1. **前足落点太浅**：8—9 cm 落在阶面，桥接时被拖下沿。需更深落点（≥15 cm）或两次小步挪深；
   更深落点受腿长限制，可先把机体靠近台阶再落足（但 v2 证明不能太近，竖直抬升位姿会撞台阶立面）；
2. **桥接期的支撑策略**：后腿抬升时建议让机体**前倾并把重心压到前足**（而不是水平移重），
   或改为「后足先挪到台阶沿、贴着立面抬升」；
3. **顺序选项**：也可考虑「先抬后腿再抬前腿」的交替上阶（每足单独上阶，机体始终有三足支撑
   在同一平面），代价是台阶高度受单腿抬升能力限制（0.10 m 在能力内）。

**结论**：V8-X1 平地步态与「两前腿落阶＋机体上抬」已完成并有证据；**完整四足上阶未完成**，
瓶颈是跨阶桥接期的后腿抬升。上述三条任一可作下一件。
