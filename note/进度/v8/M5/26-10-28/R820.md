# R820／批469：修正 IK 探测污染仿真状态——R818 闭环读数作废，修复后闭环限幅 0.12 m 可用

更新时间：2026-10-28

## 1. 实现 bug 与修复

`leg_ik` 用有限差分求雅可比时会反复改写 `data.qpos`；旧代码在求解后用 `data.qpos[7:19]=DEF`
「还原」，把仿真中的真实关节状态一并覆盖。凡是**每拍**重解 IK 的模式（drive/place），
等于每 20 ms 瞬移一次关节——物理被打爆，读数不可用。

修复：新增 `solve_leg()`，求解前备份 qpos/qvel、求解后完整还原，再 `mj_forward`。
**只有每拍重解 IK 的 R818（drive）受影响作废**；R813—R817 的 IK 都在仿真循环前一次性求解
（当时状态即 DEF，覆盖无副作用），读数有效。
