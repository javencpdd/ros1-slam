## 2. 踩到的四个真缺陷（都属"看起来能跑、其实跑不起来"）

1. **XML 注释里不能有 `--`**：我在 launch 注释里写的箭头 `-->` 直接让 roslaunch 报 `not well-formed (invalid token)`。改成 `=>`。
2. **catkin 的 relay wrapper 不能被 import**：`catkin_install_python(PROGRAMS goal_gate_policy.py ...)` 生成的是 relay 脚本——它把源码 `exec` 进一个私有 context dict，**模块本身不导出任何名字**。于是 `import goal_gate_policy; goal_gate_policy.parse_allowed` 抛 `AttributeError`。**这是我 04:32 那次"修复"引入的**。正解：入口用 `catkin_install_python`（wrapper 可执行），被 import 的模块用 `install(FILES ...)`（真实文件）。
3. **roslaunch 的 `type` 不接受子路径**：`type="planner/topic_node.py"` 报 `Cannot locate node of type ...`；`rosrun` 却接受。所以「甲方案（装入口）」对 runtime 有效，对 roslaunch 无效。正解：包根装重命名入口或写 `scripts/` shim。
4. **`catkin_make --pkg` 不执行 devel install 步骤**：改完 install 规则后文件不更新，必须手动 `cmake -DCMAKE_INSTALL_PREFIX=devel -P cmake_install.cmake`。而且 devel space **不清理旧产物**——旧的 wrapper 会一直留着，必须手工删。
