## 1. 复核结论与本批处置

独立技术复核（只读，未改仓、未启容器）对 [R627](R627.md) 的结论是 **A1 不可签**：二维/多层两类结构确实互斥、6 项测试全过，但「无空白关键语义」未达成，且契约层存在静默放行、误拒与崩溃。本批按复核逐条修实现，不改 R627 原文；R627 的证据清单保留原值，不重写。

**先更正 R627 的两处表述**（另起句，旧文不回改）：R627 第 3 节称「22 例」、第 4 节称机器人能力「全部标注为未验证设计假设」——前者现由本批 42 例取代；后者在 R627 当时并不成立（夹具里 min_clearance_m 标了 tested/allowed 却无报告），本批把该值改为 declared/prohibited，并新增 E_ROBOT_EVIDENCE 规则，使陈述与夹具一致。

## 2. 逐条落修

| 复核项 | 修法 | 可复跑的证明 |
| --- | --- | --- |
| task.xyz 每维可为 null | x/y 必为数值（E_TASK_XY_NULL）；plane_xy 目标 z 必须为 null（E_TASK_PLANE_Z）；support_surface 禁用 not_applicable（E_TASK_DISAMBIGUATION） | 3 个新反例＋修复复跑 |
| 连通性只查出边，双环假绿、单向合法被误拒 | 改为按 bidirectional 建图、从首面做可达性闭包，全部面必须可达 | 新增正控「单向 A→B 合法」与反控「两个各自闭环的子图」 |
| multiple_surfaces_per_xy 只是自报 | 多层要求至少两面，且至少一对 XY 足迹相交（E_MAP_ML_COUNT／E_MAP_ML_NO_OVERLAP）；每面新增 footprint | 2 个新反例 |
| support_map 缺 surfaces 触发 KeyError／rc1 | 按 kind 前置检查，报 E_MAP_SURFACES_MISSING／E_MAP_LAYERS_MISSING | 2 个新反例，CLI 只出理由码 |
| schema_version 用 true 绕过 const 1 | const／enum 改严格同型比较（布尔与整数不互通） | neg_manifest_version_bool |
| 空串与 NaN 放行 | 字符串 strip 后为空报 E_SCHEMA_BLANK；数值必须有限报 E_SCHEMA_NONFINITE | 2 个新反例 |
| 嵌套 additionalProperties、无 items、缺 $ref 目标静默或崩溃 | 三者一律 E_SCHEMA_UNSUPPORTED，并加 3 项校验器自测 | 3 项独立测试 |
| 边语义未参与判断（flat 可跨 0.6 m、可进不可通行面） | flat 高差 ≤ 0.05 m、step 高差 ≤ 其上限加 0.05 m（E_MAP_EDGE_Z）；不得指向 unsupported 面（E_MAP_EDGE_TRAVERSABILITY） | 2 个新反例 |
| 已声明理由码无夹具 | 新增 stop／control／tf_dup／footprint／edge_param／surface_dup／layers_missing 等反例 | 理由码与夹具一一对应 |
| 无任务↔地图交叉校验 | 新增 check_pair：map_id／map_version／surface_hint 三项（E_PAIR_*） | 配对测试含两个反控 |

夹具由 22 例扩到 **42 例**（8 正例、34 反例），测试由 6 项扩到 **10 项**：42 例逐例锁定理由码并修复复跑，另加单向边合法、双环拒绝、配对检查、校验器三项自测。现跑 10/10 通过。
