**结论＝R630 七面全部立住，但复核另查出六处缺口与一处文档矛盾，判仍需修（已当场落修，见 §2）：**

1. robot `reference_point.xyz` 只有 minItems 无 maxItems（map origin 与 task xyz 在 R630 已定长，同类残留），4 元放行；
2. polygon `points` 内层坐标无 maxItems:2，3 元点放行；
3. 足迹类型与参数不互斥：circle 带 points、polygon 带 radius_m 均放行（矛盾数据，违背「不留空白语义」，与 R630 修的 plane_xy 禁 hint 同类）；
4. 边参数与 kind 不互斥：flat 带坡度/台阶参数、slope 带台阶参数、step 带坡度参数均放行（无角色声明被静默忽略）；
5. `check_pair` 对缺 frame/map_id/map_version 的 mapping 裸抛 KeyError，失败面不是理由码；
6. README 第 28 行仍写「step 边高差不得超过其 max_step_height_m 加 0.05 m」，与 R630 去容差后的实际代码相反（实测超 0.02 即拒），会误导 V8-04/05 消费方。

观察项（不判缺陷，留后续里程碑）：support_map 必带 extent 但 22 号正文无消费定义（V8-04/08 定界）；两面厚度体积相交未判（XY 重叠与 z 差之外的 3D 几何归 V8-08）；manifest `io.inputs` 允许空数组（传感器源组件合理）；重叠判定取「至少一对」，锚点面取 surfaces[0]（已在 README §2 声明）。
