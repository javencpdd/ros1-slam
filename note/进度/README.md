## 维护约定

总览在形成有意义的版本/阶段成果时更新，同一版本的新增成果并入已有条目。日常任务由任务卡接续，实验数据留在真实实验目录；不再要求每次文档修订滚R档头、在总览末尾添一行或重复抄录三面。

旧v4—v7目录仅保留现用检查的依赖子集，其他原件按固定Git历史或仓外备份恢复。旧索引、档头历史和原证据保留原时点，旧文字不是当前开工指令。11月4日已取消的算法、地图准备和真机排程继续取消。
