## 程序运行身份与环境规范（2026-10-06 固化，全团队生效）

1. **默认以 ysc（当前登录用户）运行程序**——冒烟/测试/工具脚本/rostopic 查验一律 ysc 身份执行；仅两类操作切 `sudo -u ros1-slam`：沙箱属主文件的写入/修改、git 提交（或 root 直写后 `chown ros1-slam:ros1-slam` 归位）
2. **ros1-slam 无 sudo**——在 ros1-slam 身份的会话（tmux 等）里禁止 sudo / `sudo -u`（会报 not in sudoers）；需要 sudo 的命令回 ysc 终端执行
3. **ROS1 环境预置（防 foxy 混装）**：ysc 终端的 bashrc 常预载 foxy 生产环境——运行 ROS1 程序前必须显式准备 noetic：`unset ROS_DISTRO ROS_VERSION ROS_PYTHON_VERSION` → `source /opt/ros/noetic/setup.bash` →（沙箱工作再 source env.sh / devel）。出现 `ROS_DISTRO was set to 'foxy'` 警告 = 环境已混装，**该 shell 的命令结果不可信，重开干净 shell 重来**
4. env.sh 已内置 foxy 隔离（清 PATH/PYTHONPATH/LD_LIBRARY_PATH 中的 foxy 路径并锁 ROS_DISTRO=noetic）；不得在 foxy 预载环境下 source 沙箱 env.sh 后直接采信输出
5. tmux 长会话约定不变：会话属主决定窗内身份（ros1-slam 会话内禁 sudo；ysc 会话内 ROS 命令套 `sudo -u ros1-slam bash -c 'source env.sh && …'` 或按 3 预置）

### 每一项的五段固定形状（编号＋标题在最上，一项一节）

| 段 | 必含内容 | 判为不合规 |
|---|---|---|
