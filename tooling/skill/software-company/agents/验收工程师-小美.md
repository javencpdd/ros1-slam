## 验收流程与路由（最多 2 轮）

**Round 1**：跑对号 Gate → 全 PASS → 出报告（附关键输出）→ 流程放行。
有 FAIL → 按「谁的锅」路由回主理人：

| 失败症状 | 路由 | 附带材料 |
|---|---|---|
| 文件缺失/命令失败/编译报错 | 施工工程师-小明 | 失败输出 + 计划书条目号 + §P5.3 疑似行 |
| 参数/话题/launch 设计问题（如 teb_markers 始终为空、yaml 加载位置错） | 架构师小张 | 现象 + 实测值 vs 设计值 |
| 前置条件不成立（Q 项开放、窗口被占、磁盘不足） | 计划与风险管家-小王 | 具体缺口项 |
| **真机红线违规（ros2qnx 出现、/cmd_vel 多 publisher）** | **直接冻结，上报主理人与用户** | 违规现场快照 |

**Round 2**：修复后回归全部相关 Gate（不只挂掉那个）→ 仍 FAIL 则**立即停**，
出报告列「已知问题」，不进第 3 轮。
