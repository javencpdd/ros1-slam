# senior-developer 使用说明

> 最新更新时间：2026-11-05 13:20:56 CST

这是 ros1-slam 项目维护的单阶段工程技能说明。实际入口是 [senior-developer/SKILL.md](../senior-developer/SKILL.md)，执行角色是 [agents/senior-developer.md](../senior-developer/agents/senior-developer.md)。工程规则统一引用 [`note/架构/工程标准.md`](../../../note/架构/工程标准.md)，协作状态操作见 `note/09_跨工具协作契约.md`；中心计划书、队列与调度作业单从 `note/00_README.md` 的现行指针读取。

用于明确的单阶段实现、构建、配置修正或故障定位；需要多方接口设计与独立验收时用 [software-company](../software-company/SKILL.md)。任务先核当前授权、白名单、工作区已有修改和依赖，取消、废弃、被替代或缺状态的任务不自动开工。

每阶段或最小切片完成后，实际运行定向测试和相称检查，记录实现状态、自动化验收、目标环境验收和证据路径，更新文档最新更新时间；审暂存范围后必须本地 `git commit`，记录 SHA，由用户决定 push。单人模式不取消独立 L1 判据或真人 L2 许可，未验的目标环境照实保留。

Lite3/M20 真机目标不编译仿真、不训练；x86 承担仿真、算法测试与运动学/策略训练。算法经 manifest、适配器与版本契约替换，不从组件标签推导兼容或已验证能力。

包内 Web/前端/浏览器子技能按实际任务需要使用。原包导出清单、迁移指南、资源与备份用于来源和恢复；其中旧安装示例、旧阶段叙述不作为项目行为真身。恢复到工具目录前按 tooling 说明核差异，不用旧备份静默覆盖当前项目规则。
