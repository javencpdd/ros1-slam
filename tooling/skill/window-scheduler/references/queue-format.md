# 任务队列格式与选取规则

> 最新更新时间：2026-11-05 13:20:56 CST

适用于本项目的调度语义统一引用 `note/架构/工程标准.md` 与 `note/09_跨工具协作契约.md`。现行中心计划书、执行队列和调度作业单从 `note/00_README.md` 的现行指针读取；下列为字段约定，不要求把所有现行表强改成同一列布局。

## 字段约定

| 字段 | 语义 |
| --- | --- |
| ID | 稳定任务标识；结束或取消后不复用 |
| 任务/方向 | 具体产物与所属方向；标签不提供授权 |
| 类型/目标环境 | 离线、开发、仿真或真机等实际执行方式，需窗与真机许可单独核实 |
| 依赖 | 必需任务、输入和现场条件；缺失或未满足就不能选 |
| 状态 | 必须显式填写；当前队列的状态词以其定义为准，缺状态拒选 |
| 验收出口 | 可执行的验证与目标环境证据，不能只写“完成即可” |
| 证据/接续 | 实际产物、测试、未验范围与本地提交 SHA |

## 选取规则

1. 先核当前授权范围，再按队列依赖和优先级选明确可执行的项；只能从显式未开工、已认领进行中或条件已经实证解除的待办中选择。
2. 已完成/已验收、已取消/取消、已废弃/废弃、已替代/被替代均不自动选；缺状态或无法解释的状态也拒选，不能用“状态不等于已验收”作为可执行条件。
3. 等窗、待许可、待现场、阻塞项只有其条件实际成立且本次仍授权时才可接续；旧失败记录和缺验收不使取消项恢复。
4. 需窗任务当场执行现行预检，rc=0 才开窗；不启后台看守、不等待旧旗、不使用 FORCE。预检未通过时只阻塞该任务，独立已授权离线工作可另选；真机任务不由通用调度自动启动。

## 收尾

更新当前任务的实际状态、四要素证据和文档最新更新时间，审暂存范围后必须本地 `git commit`，记录 SHA；由用户决定 push。下一项只能来自当前仍授权且依赖满足的范围。范围已结束或剩余项均被取消/阻塞时，明确记录无下一执行项，不强行补出任务。
