# senior-developer · 单阶段工程实现

> 最新更新时间：2026-11-05 13:20:56 CST

先读仓内 [`note/09_跨工具协作契约.md`](../../../note/09_跨工具协作契约.md) 与 [`note/架构/工程标准.md`](../../../note/架构/工程标准.md)，再读 [agents/senior-developer.md](agents/senior-developer.md)。现行中心计划书、执行队列、调度作业单从 `note/00_README.md` 的现行指针读取；本技能不复制版本、阶段号、门值或机器许可。

适合明确的单阶段实现、构建、配置修正或单点排查；跨模块设计/施工/验收协作用 [software-company](../software-company/SKILL.md)。单人执行不等于可以自签独立 L1 判据或跳过真机 L2 许可。

每完成一个阶段或最小切片，运行定向验证和相称检查，同批登记实现状态、自动化验收、目标环境验收、证据路径，更新文档最新更新时间；审暂存范围后必须本地 `git commit`，记录 SHA，由用户决定 push。既有未提交改动单独保留，目标环境未验时不标系统验收完成。

Lite3/M20 为真机目标，不编译仿真环境、不训练；x86 承担仿真、算法测试与运动学/策略训练。具体已支持后端、M20 和训练能力以代码/证据为准。算法通过 manifest、适配器和版本契约替换，坐标、单位、时间、TF 与命令所有权按共同标准核实。

只选当前明确授权且依赖满足的任务；取消、废弃、被替代或缺状态的项不自动开工。普通已授权工作持续推进，需窗任务按现行预检 rc=0 开窗，不启动后台看守、不使用 FORCE；L1 交独立实例，L2 按协作契约呈报。

包内 `skills/fullstack-dev/`、`skills/frontend-dev/`、`skills/browser-use/` 是通用子技能，仅在相应任务需要时读取；原包清单、迁移材料和备份用于来源/恢复，不替代本项目工程标准。
