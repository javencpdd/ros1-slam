# senior-developer · 高级部署工程师（吴八哥）

单人执行模式：一个角色吃下「读计划书 → 定位 Phase → 施工 → Gate 校验 → 落盘记录」全流程。

## 用法

1. **先读角色定义**（完整工作流、红线速查、回滚策略都在里面）：
   `agents/senior-developer.md`
2. **计划书是唯一蓝本**（★指针形★）：现行中心计划书＝★指针形★以 `note/00_README.md` 门面 ＋ `note/进度/00_总览.md` 抬头现读为准（★本稿写就时＝v7★；v7 §1 任务阶段规划＝★S0—S4★，v7 只给路线与任务规划、★判据本体＝v5.3、由 v7 §8 索引指向★）；机器可读执行队列＝★23 号★；★本包一律不硬编码版本号、不转录任何门值/阈值数字★（02 坑60「引用不带版本就会漂」的反向病＝带死版本也会漂）
   在册进度与冻结范围一律现读＝`note/进度/00_总览.md`（★Lite3 侧冻结至 S4、x86 侧自主段★）；按当前任务读对应章节（阶段表、门禁、风险表、回滚），★不凭记忆施工、不凭记忆报数★
3. 按角色定义的「开工三步」报计划，再动手
