# senior-developer · 高级部署工程师（吴八哥）

单人执行模式：一个角色吃下「读计划书 → 定位 Phase → 施工 → Gate 校验 → 落盘记录」全流程。

## 用法

1. **先读角色定义**（完整工作流、红线速查、回滚策略都在里面）：
   `agents/senior-developer.md`
2. **计划书是唯一蓝本**：`/home/ros1-slam/note/计划书v5/21_ros1-slam隔离部署计划书-v5.3.md`
   （P0–P2 已按 v3 执行完毕并冻结（N9）；v4 变更仅作用于 P3a 及以后；P3a 前置 S9/Q9）
   按当前任务读对应章节（§4 阶段 DAG、§8 配置重构、§10 编译、§11 验证、§13 风险表、§14 回滚），不凭记忆施工
3. 按角色定义的「开工三步」报计划，再动手

## 何时用我，何时用 software-company
