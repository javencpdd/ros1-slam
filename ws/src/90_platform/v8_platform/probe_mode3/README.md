# probe_mode3 · SCAN 接缝数学探针

> 最新更新时间：2026-11-05 11:49:54 CST。本次为文档与源码核对；验收状态以[项目进度](../../../../../note/进度/README.md)为准。

[mode3_probe.py](mode3_probe.py) 离线复现 SCAN REFERENCE_PATH 的高度补偿/抽稀和 A* 搜索平面；不启动 ROS 或 SCAN，不改第三方源码。它解释接口信息损失，不能直接证明运行安全或 A3/A4 通过。

## 数学与源文件

| 行为 | 数学 | 源文件 |
| --- | --- | --- |
| waypoint 高度 | 每点无条件 `z + body_height_`；body_height 缺省 0 | [scan_replan_fsm.cpp](../../../30_3rd/plan_manage/src/scan_replan_fsm.cpp) 的 pathCallback |
| 抽稀 | 首点保留；与上一个保留点的三维距离 ≥0.5 m 才保留；终点与末保留点差 >1e-6 时回补 | 同上；min_dist 是 constexpr，不是可调参数 |
| 邻居高度 | XY 投影到起终点直线，ratio 钳 [0,1]，`z=start_z+ratio*(end_z-start_z)` | [dyn_a_star.cpp](../../../30_3rd/path_searching/src/dyn_a_star.cpp) 的 interpolateZIndexOnSearchPlane |
| XY 退化 | 起终点 XY 距离平方 <1e-8 时恒取起点 z；邻居只展开 XY | 同上 |

源码链接直接指向当前仓内副本；历史行号会漂移，以函数名定位。

## 可手算的正反例

| 输入 | 结果与限制 |
| --- | --- |
| 地面 z=0、body_height=0.28 | 输出 0.28；若上游已发体心 z=0.28，会再加成0.56，产生双重补偿 |
| body_height 未配 | 输入地面 z=0 仍为0；适配配置必须明确参考点 |
| 平地 0→2 m、步长0.1 | 抽稀后保留约0/0.5/1/1.5/2；末点不足阈值仍回补 |
| 短坡：坡脚x=0.3、坡顶(0.6,0.4) | 中点(0.45,0.2)距首点0.4924<0.5被吞；保留点直弦在坡脚高0.2，而地表为0，形成悬空 |
| (0,0,0.28)→(4,0,0.88) | 搜索平面 `z=0.28+0.15x`，可表达这一单调坡 |
| 同高起终点，中间须爬高0.6 m天桥 | 插值全程水平，单次平面搜索不能表达先上后下 |
| x=2处板体z∈[0.5,0.6]，上例插值 | z=0.58落在板体；保留多层地图也不能让单次平面搜索自动选层 |
| 同XY纯升高 | 退化分支恒取起点z，不能表达垂直转层 |
| 未知或缺支撑处输入点 | 高度补偿与抽稀不识别支撑/未知，不能承担独立支撑监督 |

高度参考应只补偿一次。连续坡与离散转层不是同一种模型；短转层锚点可能被固定抽稀吞掉，不能仅靠把全局路线交给 mode3 保证保层。

## 历史运行发现与当前用途

R633—R635 的独立 SCAN 运行探针还记录：修复搜索池有限；A* 失败可被后续优化器回退掩盖；单调段正控能出径。原读数与限定条件在[进度入口](../../../../../note/进度/v8/README.md)查 M0/26-10-25 对应批次，本文不把离线数学复跑当作重新完成运行验收。

当时提出的“支撑图切单调段再交 mode3”是历史适配候选。当前已有[支撑图全局规划](../planner/README.md)和[原生三维局部规划](../local_planner/README.md)，不能继续把后者写成尚待实现的备选。SCAN 适配损失仍在[declarations.py](../adapters/declarations.py)登记；轨迹须经[独立检查器](../validator/README.md)，被检链自报成功不能代替检查。

从仓根运行离线断言：

```bash
python3 -B ws/src/90_platform/v8_platform/probe_mode3/mode3_probe.py
```

探针覆盖到 waypoint 列表和搜索平面高度；多项式/样条平滑、占据图内部、真实传感与执行属于另行运行证据。
