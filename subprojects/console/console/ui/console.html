后端
  1. 保持 rosbridge 在线（Foxglove 走的就是它）：ws://127.0.0.1:9090
  2. Foxglove 里 Open connection → Rosbridge (ROS 1)（不要选 Foxglove WebSocket），填上面的地址。
  3. 导入布局模板：ros1_slam_sim_layout.json（建图快照）/ ros1_slam_scan_layout.json（SCAN：/cloud_registered＋阶段标记＋路径＋BT Raw）。
  4. 切到本模式时网页已停：服务端体素流、实时点云订阅、3D 渲染、/tf 等监视订阅；只留 /v8/bt/status 驱动上方 BT 阶段条。
  5. 桥连的域要一致：当前 rosbridge 连控制台域 11312；真机换桥的 master（见 docker/foxglove/README.md）。
点云/3D 交互在 Foxglove 里做；本页继续负责发目标、BT 阶段、作业栈与监控。
远程使用指南（先看这里）
  1. 确认连接：顶栏 rosbridge 显示“已连接”，作业栈 agent 显示“在线”。
  2. 起仿真/建图：在“作业栈”启动 sim_m1；需要实时点云再启 mapping_m1，需要遥控再启 safety_mux，需要服务端体素再启 voxel_stream；3D 目标必须先启 bt_console。
  3. 选图/发目标：主图是 2D 预览，先勾“地图与运行 world 一致”，再在地图上点目标，最后“发送选中”或“按顺序发送全部”。3D 目标写入权归 bt_console，控制台统一发 /v8/bt/goal；BT 未运行时 3D 发送会被拒绝。2D MBF 仍直发 /move_base_simple/goal。执行器/known-map app 走 CLI。
  4. 看 3D：点地图卡里的“打开 3D 场景”，选实体世界和图层；实时点云在 3D 场景内订阅或切“服务端体素”。
  5. 行为树：作业栈启 bt_console；Groot2 本机连接 ZMQ 5555；地图卡“交给行为树”把选中目标发到 /v8/bt/goal。
  6. 监控/遥控：遥控在地图卡下方，和 2D/3D 画面同一列；右栏看话题频率、TF、MBF 状态。遥控只走安全 mux，急停随时可用。
  7. 本机专用：Gazebo/RViz/MuJoCo、world/SDF/PCD 上传、宿主 shell 在远程灰化锁定，需在宿主桌面执行。

3D 全链不是 3D 视图：它只改变目标发布接口；2D 主图用于点选，3D 实体/点云在下方“3D 场景”。
