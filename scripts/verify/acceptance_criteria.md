## 0. 通用前置（不满足即 INVALID，不得记 PASS）

| 编号 | 判据 |
| --- | --- |
| P1 | 控制输入不取自 Gazebo 真值：`/v8/local/pose` 的唯一发布者必须是 `loc`（源 `/hdl_odom`），且 HDL 已收敛 |
| P2 | 探针自身有效：采样窗内 `/cmd_vel` 样本数 ≥ 20/s × 时长 × 0.8（证明链路在发） |
| P3 | 触发类场景（C3/C4）**触发前 3 s 内必须存在 \|v\| > 0.05 m/s 的样本**，否则该次判 INVALID（未运动不得判 PASS） |
| P4 | 判"停止"必须用**连续零速段**，不得用"首次归零"；首次归零只作延迟指标 |
| P5 | 全程节点存活：触发后 5 s 内 `rosnode list` 中 local/bt/mux/global 仍在（不得以整栈退出当"安全停止"） |

## 1. 速度与停止口径

| 量 | 判据 | 说明 |
| --- | --- | --- |
| 零速 | `\|v\| ≤ 0.02 m/s` 且 `\|ω\| ≤ 0.05 rad/s` | 单样本；不是"接近零" |
| 持续停止 | 连续 ≥ **5.0 s** 全为零速样本，中间不允许有 > 容差的样本 | 任一越界即重新起算 |
| 停止延迟 | 触发时刻 → **首个**零速样本 | 只作指标，不作 PASS 依据 |
| 滑行距离 | 触发时刻 → 持续零速段起点之间的真值位移 | 用于评估制动距离 |

## 2. 场景判据

### C1 正常导航

| 项 | 门槛 |
| --- | --- |
| 全局路径/航点 | 至少 1 条含 ≥2 点的路径，末端＝航点 |
| 局部目标推进 | `/v8/local/goal` 至少推进 1 次（航点前进） |
| 非零速度 | 采样中 \|v\| 最大值 ≥ 0.05 m/s，且非零样本占比 ≥ 20% |
| 真实位移 | 真值位移 ≥ 0.30 m |
| BT 到达 | `/v8/bt/arrived` 出现 true |
| 到达误差 | 终点与目标真值距离 ≤ **0.15 m** |
| 碰撞 | 全程真值轨迹与障碍盒最小间距 > 0（无穿透） |

### C2 障碍安全

| 项 | 门槛 |
| --- | --- |
| 可通行场景 | 与 C1 同判（必须真的走过去，不得"原地不动"充当安全） |
| 阻断场景 | 出现绕行（局部路径偏离障碍法向）或安全拒动（\|v\| 全窗 ≤ 0.02 且 local status 给出拒动原因） |
| 感知生效证据 | 阻断场景中 `/v8/local/obstacles` 非空，且 local status 的 `obstacles` 年龄 < `input_max_age_s` |
| 碰撞 | 两场景均零穿透 |

### C3 定位失效安全

数据源隔离方式：**停掉 `loc` 的唯一发布者**（或让其停止发布 `/v8/local/pose`），
**不得**另起节点发 `localization_ok=false`（那会引入第二个写者，测的不是数据源失效）。

| 项 | 门槛 |
| --- | --- |
| 触发条件 | 满足 P3（失效前确有运动） |
| 归零 | 失效后 1.0 s 内出现零速样本；并满足 5 s 持续停止 |
| 停止延迟 | ≤ 1.0 s（现有 `input_max_age_s=0.7` + `mux timeout 0.25` + 一帧余量） |
| 系统存活 | 满足 P5 |
| 恢复 | 恢复后 10 s 内不得出现非零速度（旧任务不得自动复动） |

### C4 运动中取消

| 项 | 门槛 |
| --- | --- |
| 触发条件 | 满足 P3（取消前确有运动） |
| ACK | `/v8/local/cancel_ack` 在 2.0 s 内出现（与 `cancel_ack_timeout` 对齐） |
| 归零 | ACK 后 1.0 s 内出现零速；并满足 5 s 持续停止 |
| 系统存活 | 满足 P5 |
| 不复放 | 取消后 10 s 内非零样本数 = 0；旧路径换新 stamp 重发仍不得驱动 |
| 新任务 | 取消后下发合法新任务（含同坐标）能重新启动（出现非零速度） |

## 3. 补充场景（本轮必测）

| 场景 | 判据 |
| --- | --- |
| 感知断流 | 停 `perception` 唯一发布者 → 0.7 s 内 `obstacles` 超时 → 5 s 持续停止；满足 P5 |
| TF 失效 | 停 `map→rslidar`（或 `base_link→rslidar`）发布者 → 点云无法变换 → 障碍心跳不得刷新 → 5 s 持续停止；满足 P5 |
