## 1. 一句话结构

系统是**三条装配链＋一个 host-only 测试面＋一层平台治理**，真机执行段整体处于 L2 边界内：

1. **传统 ROS1 导航链（已接通）**：驱动 → faster-lio → costmap/MBF（GlobalPlanner/Navfn＋TEB/DWA）或 SCAN → `safe_cmd_vel_mux` → `/cmd_vel` → Gazebo 平面载体；真机段 `/cmd_vel → ros2qnx → QNX 43893` 默认关闭（`enable_motion=false`）。
2. **SCAN＋BT 编排链（本会话主线，仿真已验证）**：web 3D 目标 → BT.CPP 编排树 → SCAN 规划/跟踪 → 桥回传路径/到达 → mux → 载体；平地 A* 与 10°/1.4° 坡面参考路径两 profile 全链 PASS（scoped）。
3. **v8 组件化 3D 链（限定场景运行）**：app/graph YAML → 支撑图全局 A* → 3D 局部 → cmd3d mux → 运动学载体；two_floor_nav 4/4 PASS（known-map＋kinematic，不签四足物理）。
4. **host-only 测试面**：web 任务台＋白名单 agent（12 栈）＋rosbridge＋Foxglove 双模＋体素流＋bag 录制；不进机器人 target/镜像。
5. **平台治理**：contracts/registry/composer/graph/execution/Assembly 有真实运行入口，但 TF 所有权、统一 I/O、热替换等整改项（V81-01—05）未闭合。
