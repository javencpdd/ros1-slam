④ 关键接缝（这些决定了“是不是一个系统”）

mux → boundary 未接：现有 /cmd_vel 是事件驱动；50–500 Hz 定拍 UDP 只在 127.0.0.1 回环验证过，未从 mux 取命令。
boundary 无上行：没有遥测帧与状态回传，FAULT/断链安全状态机尚未落地；代码只做零速保持。
v8 治理层与运行层断开：contracts/registry/composer/orchestrator 仅经 SimulatedRunner 验证；planner/validator/representation 未接 A5/MBF/SCAN。
两类仿真不等价：MuJoCo 有接触动力学但只接 A5 支撑图 pilot；Gazebo 3D 载体是运动学 SetModelState，不能证明四足爬楼物理可行。
真机链路仍是厂商路径：ros2qnx 逐条 sendto QNX 43893（事件驱动），换定拍链路需 L2 与台架验证。
